# ADR-038 分段模型與各階段的不變式

狀態：已核可（2026-10-11）。決策 4 的「潤飾與翻譯以 VAD-A 為單位送出」已由 [ADR-049](ADR-049-batches-with-read-only-context.md)（2026-10-13）修訂為批次加唯讀語境；字幕長度與輸出時的合併見 [ADR-050](ADR-050-subtitle-length-and-merge.md)。回答：VAD-A、VAD-B 如何定義，以及為何各階段不得改變字幕條目的數量與時間。

## 背景

潤飾、核對與翻譯由 LLM 處理文字，可能合併、拆分或搬動條目，破壞時間軸與畫面對應。

## 決策

0. **語音機率**：VAD 工具對整個 WAV 輸出一次機率序列；VAD-A 與 VAD-B 都是 pipeline 對這份機率套用判定參數（門檻、最小靜音、最小語音長度）的結果，判定規則對應官方 silero-vad 的語音區間偵測。
1. **VAD-A**：以較長的最小靜音偵測語音區間；長度超過 `maxSegmentSeconds` 的區間，在其內尋找短時間能量最低的點切開（搜尋範圍為 `cutSearchWindowSeconds`，且切開後兩側皆不短於最小片段長度），對剩餘部分重複，直到每段都不超過上限。
2. **VAD-B**：VAD-A 中長度超過 `refineThresholdSeconds` 的區間，只對該區間以較短的最小靜音再偵測，得到子區間；其餘 VAD-A 區間原樣成為一個 VAD-B 段。每個 VAD-B 段屬於且僅屬於一個 VAD-A。
3. **字幕條目來自 VAD-B 段或補掃窗口**（[ADR-044](ADR-044-asr-coverage-sweep.md)）。轉錄階段結束後，每個條目的起訖時間固定，之後所有階段只能改變文字。
4. **階段邊界**：潤飾與翻譯以 VAD-A 為單位送出；核對以條目為單位。回答必須含相同數量、相同順序、相同時間的條目；違反者視同失敗，重試用盡後退回上一階段文字並記錄降級。
5. 核對階段每個條目的畫面為其區間每秒一張；超過 `maxFramesPerRequest` 時等距取樣至上限（預設 6）。
6. 階段依模型分批：全部轉錄完成後才開始任何 gemma4 階段，以減少 Lemonade 的模型切換。
7. 翻譯的目標語言固定為繁體中文；來源語言由模型從內容判定並記錄，不作為輸入參數。輸出一律 SRT。

## 取捨

- 得到：時間軸穩定、畫面對應可靠、可逐階段比對文字。
- 失去：潤飾無法跨條目重排句子（條目數固定）；轉錄時被切開的句子只能在文字層面修補。

## 後果

測試的重點是不變式與退回規則；見 [WI-1408](../work-items/WI-1408-vad-a-b-segmentation.md) 至 [WI-1412](../work-items/WI-1412-translation.md)。
