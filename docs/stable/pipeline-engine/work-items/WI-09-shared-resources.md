# WI-09 跨 pipeline 共享資源

目標：管理員定義共享資源，pipeline 在初始化階段取得宣告的資源，以互斥或限流方式使用。

## 行為與驗收條件
- 管理員可建立、查詢、修改容量、停用資源（名稱與容量）。
- Pipeline 在 metadata 宣告所需資源名稱。
- Run 在 pipeline 本體執行前有「初始化」階段；在此階段取得所有宣告的資源。
- 取得是整體的：所有宣告的資源與並行額度同時可用時才一併取得；不會出現只取得部分資源而等待其餘的情況。
- 容量 1 的資源，同時只有一個 run 持有；容量 N 的資源，同時最多 N 個。
- 兩個不同 class loader 的 run 競爭同一資源時，互斥確實成立（可測試）。
- 等待者依先進先出取得；等待逾時由 Engine 組態設定，逾時則 run 失敗並註明「等待資源逾時」。
- 等待資源的 run 不占用並行額度，不阻擋其他不相關的 run。
- Run 以任何方式終止時，其持有的資源都被釋放。
- 等待中被取消的 run 從佇列移除，且不取得資源。
- 逾時未結束的持有者維持占用；管理員可強制釋放。
- 管理員可看到每個資源的持有者與等待者。
- Pipeline 宣告了不存在或已停用的資源時，上傳判定中顯示警告，建立 run 時失敗。
- 開發入口提供同語意的本機實作，初始化立即成功。
- 等待、取得、釋放都有 log 與 metric（等待時間、持有時間、佇列長度）。
