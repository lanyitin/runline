# ADR-080 摘要的降級條件：只有「沒有素材」降級，其餘盡量保存

本文回答：摘要階段在哪些情況下不呼叫模型或不採用回答（降級），哪些情況保存資料。狀態：已核可（2026-10-18）。補充 [ADR-069](ADR-069-accept-what-can-be-used.md) 決策 3、6、7 與 [ADR-054](ADR-054-scene-summaries-and-translation-context.md) 決策 7；與 stable 的「能收就收」原則一致。依據見[量測報告](../summary-leak-experiment-report.md)。

## 背景

- 一次 run 耗時數小時，重跑的成本高；使用者的原則是品質優先，但盡量保存資料，事後能找出哪些單位降級即可。
- 量測：片段沒有字幕且沒有圖片時，模型回答「沒有資料可摘要」，或憑空編造內容；這種回答被存成正式的片段摘要。
- 場景摘要的欄位固定為四個；run 38 場景 30 的摘要在欄位之後接了未寫完的自言自語，一併被保存。

## 決策

1. **沒有素材的片段直接降級，不呼叫模型**：片段沒有字幕，且沒有取得任何畫面時，該片段的摘要視為缺少，原因標為「沒有輸入」。有畫面但沒有字幕的片段照常摘要。
2. **沒有素材的場景與影片同理**：場景內沒有任何可用的片段摘要時，不呼叫模型，場景摘要視為缺少；影片內沒有任何可用的場景摘要時，同樣不呼叫模型，全片摘要視為缺少，原因同為「沒有輸入」，計入降級。影片完全沒有場景時沒有東西可摘要，不算缺少。
3. **欄位固定的層，保存時只取欄位區塊**：場景層與中間彙整的回答，保存時裁掉第四個欄位（`Ending`）那一行之後的所有內容。被裁掉的文字仍留在該次呼叫的紀錄（EXCHANGE）中，不丟失。適用於回答完整與被截斷的兩種情況。只在回答以標記開頭時套用（有 [ADR-077](ADR-077-scene-summary-answer-opening.md) 的預填時恆成立）；標記之前有前言或推理的回答可含多個標記與多組欄位，沒有可靠的邊界，不裁剪。
4. **被截斷但四個欄位完整**：不標示為被截斷（[ADR-079](ADR-079-truncated-summary-is-kept-and-flagged.md)）。
5. **降級不計入及早止損**：上列降級是輸入內容的結果，不累計連續失敗；及早止損仍只處理服務層失敗。
6. **降級的單位事後可查**：被降級的片段與場景，保留降級原因（例如沒有輸入），使用者事後能列出是哪些；不新增階段計數或警告，維持現有紀錄。
7. **其餘不降級**：回答不是英文、欄位缺漏、含編造的細節、輸入互相矛盾，都不降級；欄位缺漏的處理見 [ADR-079](ADR-079-truncated-summary-is-kept-and-flagged.md)，編造與矛盾由 [ADR-077](ADR-077-scene-summary-answer-opening.md)、[ADR-078](ADR-078-segment-summary-wording.md) 預防。回答中「沒有資料」類的文字不做比對。

## 取捨

- 得到：不再把「沒有資料可摘要」或編造的文字存成片段摘要；少一次無意義的呼叫；場景摘要不含欄位之後的殘文字；降級不會讓 run 提前停止。
- 失去：
  - 沒有任何場景摘要時全片摘要缺少，也算一筆降級：沒有影像又沒有對白的影片，片段、場景、全片各算一筆；
  - 沒有素材的片段在場景層是缺少的一行輸入；若整個場景如此，場景摘要缺少，翻譯照常進行但少一段語境（[ADR-054](ADR-054-scene-summaries-and-translation-context.md) 決策 7）；
  - 裁掉欄位之後的內容，若模型在欄位之後寫了有用的資訊也會丟失（仍留在紀錄中）；
  - 預填被忽略或 thinking 開啟時回答可能不以標記開頭，這類回答不裁剪，欄位之後的內容照舊保存；
  - 判斷「沒有素材」依賴畫面是否取得；畫面取得失敗與影片本身沒有畫面無法區分。

## 後果

- 「沒有輸入」是新的降級原因；片段摘要、場景摘要與全片摘要的「是否缺少」要能記下原因（實作：`segment_summary.missing_reason`、`scene_summary.missing_reason` 為 schema 版本 17，`result.summary_missing_reason` 為版本 18）。
- 場景層的解析需認得第四個欄位的結束位置。
- 工作項：[WI-1485](../work-items/WI-1485-no-input-degradation.md)（決策 1、2、5、6）、[WI-1486](../work-items/WI-1486-scene-summary-field-block-only.md)（決策 3、4）。

## 待確認問題

1. 已解答：欄位固定的層被截斷、且一個完整欄位也沒有時，保存殘文字，不降級（[ADR-082](ADR-082-truncated-with-no-complete-field-is-kept.md)）。
2. 「沒有素材」的片段占比未知；若一部影片大量如此，場景摘要缺少的比例會偏高，需要在實作後看 run 的資料。
