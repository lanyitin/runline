# ADR-010 網路與外部行程允許清單的比對規則

狀態：已核可（2026-10-03）。補充 [ADR-002](ADR-002-context-and-unsafe.md)。回答：context 如何判定一次網路連線或外部行程執行是否落在允許範圍內。

## 背景

ADR-002 規定網路連線與外部行程的限制可以是允許範圍或不限制，但未規定比對方式。core 模組已實作一組規則，後續的 Runner、靜態分析、錄製與 metadata 提案都依賴同一套語意。

## 決策

- 網路：以目標主機名稱比對，不分大小寫；不支援萬用字元；不比對埠號。
- 外部行程：以指令的第一個元素完全比對；`git` 不放行 `/usr/bin/git`。
- 空的允許清單代表全部拒絕；未提供限制代表不限制。
- 參數目前只支援字串。

## 取捨

| 項目 | 優點 | 缺點 |
|---|---|---|
| 不比對埠號 | 宣告簡單，錄製後概括化容易 | 同一主機的任意埠都放行，限制較寬 |
| 行程完全比對 | 語意明確，不會誤放行 | 作者需寫出與實際呼叫一致的指令名稱 |
| 參數僅字串 | 契約簡單 | 型別轉換由 pipeline 自行處理 |

## 後果

- WI-04 的 metadata 提案以主機名稱與指令名稱為單位概括化。
- 需要埠號或萬用字元時，另開 ADR 修訂本決策。
- 檔案存取的符號連結檢查與使用之間存在時間差，沿用 ADR-002 的協作式模型，不視為本決策的缺陷。
