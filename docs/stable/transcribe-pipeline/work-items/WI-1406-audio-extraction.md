# WI-1406 音訊擷取與畫面擷取能力

狀態：已核可（2026-10-11）。條目 1 的長度上限指參數 `maxMediaSeconds`，參數的宣告由 [WI-1415](WI-1415-max-media-seconds-parameter.md) 接上。實作已完成於 runline-transcribe 工作樹（能力以建構子引數接收長度上限），待驗收。儲存庫：T。相依：WI-1403。

## 驗收條件

1. 以 ffprobe 檢查：有可用音訊串流、長度不超過 `maxMediaSeconds`；無音訊、檔案損毀、超過長度上限各有明確失敗原因。
2. 任何 ffmpeg 可解碼的影片（至少 mp4、mkv、webm、mov 各一個真實樣本）都產出單聲道、16000 Hz、16 位元 PCM 的 WAV，位於本 run 的工作目錄；多音訊串流時使用第一個，並記錄。
3. 能就影片與一個時間區間（秒）擷取每秒一張的畫面，縮圖到 `frameMaxEdgePixels`；超過 `maxFramesPerRequest` 時等距取樣至上限；回傳的畫面只在記憶體或隨即刪除的暫存檔中，不寫入資料庫。
4. 回傳每張畫面的時間點，供紀錄使用。
5. 外部行程有逾時；取消時行程被終止；ffmpeg 不存在或失敗時原因明確（含結束碼與錯誤輸出的摘要，不含影片的絕對路徑）。
6. 檔名含空白、引號、非 ASCII 字元時仍正確處理（行程參數逐一傳遞）。
7. 測試使用真實 ffmpeg 與以 ffmpeg 產生的樣本影片。

## 架構約束

不經 shell；不保存媒體；工作目錄在 run 結束時刪除。
