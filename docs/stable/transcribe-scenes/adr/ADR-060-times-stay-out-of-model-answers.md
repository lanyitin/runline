# ADR-060 條目時間不送給模型也不由模型回傳

本文回答：潤飾與翻譯的請求與回答要不要帶條目的時間軸。狀態：架構師依使用者的自主決策授權決定（2026-10-15），待使用者回顧。修改 [ADR-053](ADR-053-polish-with-frames-and-speaker-turns.md) 與 [ADR-054](ADR-054-scene-summaries-and-translation-context.md) 中「回答保留條目時間」的作法（目標不變：條目的數量、序號、時間不被改動）、[05](../05-ipc.md) 的條目不變式，以及 [WI-1457](../work-items/WI-1457-polish-with-turns-and-dash.md)、[WI-1459](../work-items/WI-1459-translation-with-context.md) 的「時間不變」檢查方式。

## 背景

- 實機測試（run 9、run 12，相同影片段）：潤飾與翻譯的回答中，模型把時間軸的毫秒數抄錯（例如 `33,824` 寫成 `33,840`，`34,624` 寫成 `34,642`），其餘各行逐字正確。
- 原因：對齊產生的時間是任意毫秒值，模型把它們當成要「修正」的數字。
- 後果：違反「時間不變」的契約，重試 3 次仍失敗；連續 5 次達及早止損，run 失敗，整部字幕沒有輸出。run 9 同區間也有同樣的失敗，只是前後有成功的呼叫才沒有累計到門檻。
- 時間對模型判斷文字內容與換人沒有必要資訊。

## 決策

1. **不送時間**：潤飾與翻譯的請求，各條目只帶序號與文字（含行），不帶時間軸。片段的整體時間範圍可用一句文字說明，供模型了解位置，但不作為契約的一部分。
2. **不收時間**：回答只含序號與文字（含行與換人標記）；條目的時間由 pipeline 依序號從來源補回。回答若帶了時間軸，忽略，不視為違反。
3. **檢查**：條目數、序號、行數上限、換人標記位置、語境不得出現在回答中，維持原有檢查；「時間被改」這一類違反不再存在。
4. **語境**：前一片段的語境同樣不帶時間。
5. **及早止損不變**：潤飾、摘要、翻譯的契約違反仍計入連續失敗；移除時間後，最常見的假性違反消失，真正的系統性問題仍會被攔下。

## 取捨

- 得到：消除因抄寫毫秒數造成的假性失敗；請求更短；中文與來源語言字幕的時間必然一致。
- 失去：模型看不到停頓長度，換人判斷少了一項輔助線索（畫面與文字仍在）；若日後證明停頓對換人判斷有幫助，另開 ADR 以文字形式提供（例如「與上一條相隔約 N 秒」），仍不要求模型回傳。
