# ADR-053 潤飾附畫面並記錄換人，SRT 依參數畫出對話破折號；刪除畫面核對

本文回答：潤飾要做什麼、換人如何記錄與呈現、畫面核對為何刪除。狀態：已核可（2026-10-14）。修訂 stable 入口文件的範圍外「說話者辨識」；取代畫面核對階段（[ADR-038](../../../stable/transcribe-pipeline/adr/ADR-038-segment-model-and-stage-invariants.md) 決策 4、5 中與核對相關的部分）。

## 背景

使用者讀現行字幕時看不出是兩人對話還是一人獨白。VAD 依靜音切段，同一條目內常含兩人的話。使用者要求以對話破折號標出換人、兩份 SRT 都要，並能以參數關閉。

## 決策

1. **潤飾的任務**：以場景片段為單位（[ADR-052](ADR-052-scenes-as-llm-units.md)），附畫面與唯讀語境：
   - 修正轉錄錯誤；
   - 把每個條目的文字分成至多兩行；
   - 標出每一行是否為新說話者的開頭。

   不可新增、刪除、合併、拆分、重排條目，不可改時間。
2. **換人是資料**：每個條目在每個階段的文字以「行」記錄，每行有「是否為新說話者的開頭」的標記（ENTRY_LINE）。模型的回答以行首破折號表示換人，pipeline 解析後存成標記並從文字中拿掉。
3. **呈現規則**：輸出 SRT 時，若參數 `subtitleDialogueDash` 開啟，每個標記為新說話者開頭的行在行首加上對話破折號。
   - 一個條目內有兩人時，兩行都加。
   - 前一條是另一人時，這一條的第一行也加。
   - 一人獨白的連續條目都不加。

   參數關閉時，不畫任何破折號，其他內容相同。
4. **兩份一致**：翻譯必須保留每條的行數與換人標記（[ADR-054](ADR-054-scene-summaries-and-translation-context.md)）；兩份 SRT 由同一份條目與換人資料畫出，換人位置一致。
5. **失敗**：片段重試用盡時保留轉錄文字（單行，不標換人），計入降級。
6. **thinking**：預設關閉（[ADR-055](ADR-055-thinking-policy-and-early-stop.md)）。
7. **刪除畫面核對**：核對階段與其參數移除。
   - 用畫面修正文字的價值已由潤飾取代。
   - 每條一次的呼叫是成本最大的階段。
   - 格式類檢查（時間、長度、行數）由組成條目與輸出的程式保證。

## 取捨

- 得到：讀者看得出輪替；切換破折號不必重跑模型；少一個階段與約 N 次呼叫。
- 失去：
  - 換人是模型依文字與畫面的推斷，會有錯；
  - 不標出說話者是誰；
  - 逐條看畫面的細緻度降為以片段看畫面。

## 後果

- 新增參數：`subtitleDialogueDash`（預設開啟）。
- 移除參數：核對相關的參數（`verifyModel`、`verifyThinking`、`verifySystemPrompt`、`maxFramesPerRequest` 等）。
- 潤飾的 system prompt 預設值改寫，並保留「條目數、序號、時間不變」的要求。新規則包含：只在確定時修正、不以發音不同的詞替換、以行首破折號標出換人（依據：[02](../02-current-state.md) 的 prompt 實驗）。
- 正確率由 WI-1452 抽樣驗證。
