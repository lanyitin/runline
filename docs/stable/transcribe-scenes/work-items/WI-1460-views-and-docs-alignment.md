# WI-1460 Console view 與文件對齊

本文回答：Console 的「資料」區與各份文件要如何反映新流程。狀態：已核可（2026-10-14）。相依：WI-1459。儲存庫：T（view 宣告與 README），R（runbook、入口文件、資料模型等 stable 文件的對齊稿）。

## 行為與驗收條件

1. **view**：transcribe 宣告的 view 改讀新資料，至少回答：
   - 最近的 run 與結果；
   - 某 run 的各階段計數與耗時；
   - 某 run 的場景與片段；
   - 某 run 的條目在轉錄、潤飾、翻譯的文字與換人；
   - 降級的片段與原因；
   - 全片摘要、角色表、場景摘要。

   舊 run 在新 view 中標示為舊格式，不轉換舊資料；核對與補掃的 view 移除或只供舊 run。
2. **runbook**：參數、log 的讀法、查詢、降級、排錯（含止損與推理紀錄）、容量與耗時（以實測取代估計）改寫成新流程的現況。
3. **入口文件與資料模型**：參數表、處理階段圖、資料模型反映新流程。
4. 文件只描述現況，不寫變更敘事；runline 的 stable 文件以 draft 對齊稿交付，由架構師與使用者晉升。

## 架構約束

- view 是唯讀查詢，不顯示可能含機密的內容。
- 不改 pipeline 的行為。
