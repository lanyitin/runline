# WI-64 全路由的手機尺寸驗證與文件

本文回答：如何證明所有路由在手機尺寸可用，以及文件如何描述這項能力。狀態：已核可（2026-10-13）。相依：[WI-62](WI-62-responsive-information-pages.md)、[WI-63](WI-63-responsive-admin-and-forms.md)。

## 行為與驗收條件

- 盤點 Console 的全部路由（含需要特定資料才顯示的狀態，如有資料與無資料、載入失敗），每個路由在 360px、390px、768px 下以真實瀏覽器驗證：整頁無水平溢位、導覽可開關、主要操作可點。盤點清單列於回報，沒有涵蓋的路由要說明原因。
- 驗證涵蓋開發人員與管理員兩種角色看到的頁面。
- 發現的溢位或不可點之處就地修正；若修正需要改變 ADR-048 的規則，停下來回報請架構決定。
- 既有的寬版面 e2e 與 Console 單元、契約測試全部通過。
- 文件：Console 的 e2e 說明記載手機尺寸驗證如何執行；stable 的 ADR-015 加一句指向 ADR-048；不複製 ADR-048 的內容。
- 回報列出未驗證的部分（例如真機、iOS Safari 的實際行為），由使用者事後驗收。

## 架構約束

- 不新增斷點或版面分類。
- 不修改 Engine 與 API。
- 測試不使用 Stub 或 Mock。
