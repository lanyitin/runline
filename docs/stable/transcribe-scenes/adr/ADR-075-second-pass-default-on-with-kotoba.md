# ADR-075 二次轉錄預設開啟，預設模型為 Kotoba-Whisper，run 語言由首次轉錄的書寫系統決定

本文回答：二次轉錄的預設值、預設模型只支援日語時如何限定範圍，以及 run 語言在沒有參數時如何決定。狀態：已核可（2026-10-16）。取代 [ADR-073](ADR-073-whisper-second-pass.md) 的決策 2 與決策 7，以及其待確認問題中「預設是否開啟」「第二個轉錄模型的建議值」「取樣偵測的取樣數與門檻預設值」三項；其餘決策不變。

## 背景

- 使用者決定預設開啟，並以 Kotoba-Whisper-v2.0 為預設模型；Lemonade 主機上已註冊該模型（`user.Kotoba-Whisper-v2.0`，whispercpp，日語專用）。
- 量測（34 個片段）：Kotoba 的結尾幻覺句 0 次、非日文雜訊 0 個片段、短句重複 6 個片段，中位耗時 0.35 秒；以寬鬆規則計算的 14 個降級片段中可讀日語為 11（Whisper-Large-v3-Turbo 為 13）。沒有人工聽測。
- Kotoba 只支援日語，不能用來偵測語言。Qwen3-ASR 回報的語言在日語音訊上不可靠（回報為中文）。
- 一支日語影片的 202 條首次轉錄中，含假名的 113 條、無假名且非語助詞的中文句子約 37 條；含假名的比例在這 150 條實詞文字中約 75%。

## 決策

1. **預設開啟**：第二個轉錄模型參數的預設值為 `Kotoba-Whisper-v2.0`；空值表示關閉。
2. **語言範圍**：新增參數「執行二次轉錄的語言」，預設為日語。run 語言不在清單內時，不做二次轉錄，log 說明原因與 run 語言；行為與關閉時相同。非日語的影片要使用二次轉錄時，須同時改第二個轉錄模型為多語模型並把語言加入清單。
3. **run 語言的決定**（取代 ADR-073 決策 2）：
   - 呼叫端提供語言參數時，以它為準；
   - 否則，由第一次轉錄成功的文字決定：排除只含語助詞或擬聲的文字後，以文字的書寫系統分類（含假名為日語，含諺文為韓語，只有漢字為中文，其餘為其他），某一類占比不低於門檻時，採該類的語言；
   - 門檻為參數，預設 0.5；沒有任何一類達到門檻、或可分類的文字少於最低數量時，不做二次轉錄，log 說明原因。
4. **設定類失敗不使 run 失敗**：第二個轉錄模型不存在、未被資源放行等設定類失敗（[ADR-057](ADR-057-asr-endpoints-and-alignment-word-timing.md) 所述不重試的類別）時，本次 run 其餘片段不再嘗試二次轉錄，log 與 RUN SUMMARY 說明原因，run 照常進行。
5. **品質守門不變**：ADR-073 的採用規則（不是低資訊量、語言相符、去除幻覺句後仍有文字）照舊；預設開啟的風險由它與保留第一次轉錄文字承擔。

## 取捨

- 得到：不需要使用者額外設定，日語影片的中文化片段與降級片段自動補救；沒有額外的偵測模型，run 語言由已有的文字決定。
- 失去：
  - 預設開啟但沒有人工聽測的證據。採用規則只擋語言與低資訊量，不擋同為日語的錯字，可能把原本可用的片段換成較差的日語文字。緩解：只觸發降級與語言不符的片段、保留第一次轉錄的文字、第二個轉錄模型參數留空即可關閉。
  - 書寫系統的分類只能分出語系，混語影片與只有漢字的日語對白會被誤分；誤分的結果是不做二次轉錄，不會改壞文字。
  - 非日語影片預設沒有二次轉錄。
- 不採用：以多語 Whisper 做語言偵測，再用 Kotoba 轉錄：兩個模型輪流載入，成本與複雜度高，且首次轉錄的文字已足以決定語系。

## 後果

- [WI-1481](../work-items/WI-1481-whisper-second-pass.md) 的參數、預設與驗收條件依本決策改寫。
- 04、05、06、07 與入口 README 對齊二次轉錄。
- Lemonade 主機必須保有已註冊的 Kotoba 模型；Engine 資源的放行模型清單（`allowedModels`，若有設定）須包含它。
- 部署新版本時，Kotoba 缺少的主機仍可運作：依決策 4 略過二次轉錄。

## 待確認問題

- 預設開啟後的品質：需要使用者人工聽測 A、B 組片段，確認 Kotoba 的日語文字比 Qwen 的結果更接近實際。影響：結果不佳時應把預設改回關閉。
- 書寫系統分類的門檻與最低文字數量的預設值：以現有資料為 0.5；需要更多影片驗證。
