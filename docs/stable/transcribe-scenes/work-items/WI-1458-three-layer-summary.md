# WI-1458 片段、場景、全片三層英文摘要與角色表

本文回答：摘要如何以場景片段附畫面、以英文描述行為與情緒，並彙整成場景摘要、全片摘要與角色表。狀態：已核可（2026-10-14）。相依：WI-1457。決策見 [ADR-054](../adr/ADR-054-scene-summaries-and-translation-context.md)。儲存庫：T。

## 行為與驗收條件

1. **語言**：三層摘要與角色簡述一律以英文撰寫，不論來源語言。
   - 角色名保留片中出現的寫法；沒有名字者用英文的描述性稱呼。
   - 主要文字不是英文的回答視同契約違反，依重試與降級規則處理；檢查容許夾雜角色名與片中原文的短引用。
   - 測試涵蓋日語來源的影片與英語來源的影片。
2. **片段摘要**：每個場景片段一次請求，附畫面與潤飾後的條目（沒有條目的片段只附畫面）。回答以 `SUMMARY:` 標記，描述：
   - 在場的人（名字或描述性稱呼）；
   - 在做什麼、情緒、場所。
3. **場景摘要**：每個場景以純文字彙整其片段摘要，回答以 `SUMMARY:` 標記。
4. **全片摘要**：以純文字彙整場景摘要，回答含 `LANGUAGE:`、`CHARACTERS:`、`SUMMARY:` 三個標記：
   - 角色表每列一個角色，含名字（片中出現者）或描述性稱呼與一句英文簡述；
   - 全片摘要依主題或段落組織，不逐場景條列。
5. **角色名**：預設 prompt 要求名字只採用對白或畫面中出現者，不確定時用描述性稱呼。
6. **輸入過大**：任一層的輸入超出單次請求的預算時，分批彙整後再彙整（沿用現行摘要的分批作法）。
7. **失敗**：任一層缺摘要時記為缺少（不以空字串冒充成功），上一層以現有內容照常彙整，計入降級。
8. **紀錄**：SEGMENT_SUMMARY、SCENE_SUMMARY、CHARACTER 與 RESULT 的全片摘要依 [06](../06-data-model.md) 寫入；三層的 system prompt 各有參數可覆寫，不得刪去標記。
9. 舊的組摘要不再寫入；舊 run 的資料照常可查。

## 架構約束

- 摘要不改條目、行與換人資料。
- 畫面只在記憶體。
- 嚴格 TDD；測試不使用 Stub 或 Mock。
