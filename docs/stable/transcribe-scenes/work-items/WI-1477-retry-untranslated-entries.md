# WI-1477 翻譯中未翻譯的條目重試一次，只重送那些條目

本文回答：翻譯回答中含假名的條目如何重試。狀態：已核可（2026-10-15）。相依：WI-1473（已完成）、WI-1475（重試政策；須先完成，兩者改同一處）。決策見 [ADR-070](../adr/ADR-070-untranslated-entries-are-retried.md)。儲存庫：T。與 [WI-1475](WI-1475-retry-and-early-stop-policy.md) 對「未翻譯不重試」的敘述衝突時，以本項為準。

## 行為與驗收條件

1. 翻譯回答解析後，片段內有條目被判為 `UNTRANSLATED` 時，對該片段重試一次；沒有未翻譯條目時呼叫次數與現在相同。
2. 重試請求只含未翻譯的條目，序號沿用原序號；上下文與提示詞和第一次相同，不附原因。
3. 已採用的條目不重送、不被重試的回答覆蓋；重試的回答以同樣的寬鬆方式解析。
4. 重試後仍未翻譯的條目降級（保留上一階段文字，原因 `UNTRANSLATED`）；不再重試。
5. 重試與服務層失敗、空手而回的重試共用 `modelRetries`（每片段）；`modelRetries` 為 0 時不重試；該片段已用盡次數時不再為未翻譯重試。
6. 未翻譯的重試不累計及早止損的失敗；片段只要取到任何一條就歸零。
7. 紀錄：EXCHANGE 標示為重試，原因註明未翻譯；log 與 RUN SUMMARY 列出為未翻譯而重試的片段數與救回的條目數、仍降級的條目數。
8. 續跑（WI-1467、WI-1470、WI-1472）：被降級或重新檢查不通過的條目重做時，同樣套用這個重試。
9. 重現情境（假服務）：
   - 第一次回答有 2 條含假名，重試回答正確：2 條被採用，片段不降級，呼叫 2 次；
   - 重試回答仍含假名：該條降級，呼叫 2 次，不再重試；
   - 第一次回答的其他條目不被重試覆蓋；
   - `modelRetries` 為 0：不重試，直接降級；
   - 沒有未翻譯條目：呼叫 1 次。

## 架構約束

- 不改 Engine；不新增參數；不改 schema。
- 嚴格 TDD；測試不使用 Stub 或 Mock。
- 測試範圍依 tdd-coder 定義的 §1.1，只跑與異動相關的測試，不跑全套。
- 不改轉錄與其他階段的重試規則。
- 回報時列出測試範圍與結果、jar 路徑與 sha256、提交。
