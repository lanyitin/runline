# WI-1411 畫面核對與影片摘要

狀態：已核可（2026-10-11），未開始。儲存庫：T。相依：WI-1404、WI-1406、WI-1410。

## 驗收條件

1. 每個非空條目一次請求：潤飾後文字、前後條目作語境、該條目時間區間的畫面（每秒一張，最多 `maxFramesPerRequest`，預設 6，超過時等距取樣）；回答為修正後文字與一句畫面觀察。
2. 修正後文字寫入核對欄位，畫面時間點與觀察寫入紀錄；條目的時間不變；圖片不寫入任何持久處或 log。
3. 回答格式錯誤或文字為空而條目原本非空：重試，用盡後沿用潤飾文字（降級）並記錄原因。
4. 摘要階層式產生：每個 VAD-A 組由其條目的觀察與核對後字幕彙整，再由各組結果產生全片摘要；輸入量超過模型內容上限的假設不成立，必須分批；摘要語言為來源語言，同時記錄模型判定的來源語言。
5. 摘要失敗時 run 仍成功，結果標記摘要缺少（降級），翻譯階段在沒有摘要的情況下仍可進行。
6. 每次呼叫寫入對話紀錄（圖片以時間點代替）。
7. 使用自製的簡易真實對話服務（可檢查收到的圖片張數與大小）與真實 ffmpeg 測試；張數上限與等距取樣各有案例。

## 架構約束

不保存圖片；請求大小須在資源設定的上限內，超過時降低縮圖邊長而不是丟棄條目；階段在潤飾完成後才開始。
