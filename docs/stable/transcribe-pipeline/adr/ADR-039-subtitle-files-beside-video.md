# ADR-039 字幕檔寫在影片旁邊，檔名為「影片檔名_語系.srt」

狀態：已核可（2026-10-12）。補充 [ADR-037](ADR-037-unsafe-pipeline-and-intake-root.md)（pipeline 開始在收件根目錄內寫入）。字幕檔的內容為合併顯示後的 SRT，見 [ADR-050](ADR-050-subtitle-length-and-merge.md)（2026-10-13）。與既有文件衝突，以本文為準，並由 [WI-1420](../work-items/WI-1420-subtitle-export.md)、[WI-1421](../work-items/WI-1421-writable-intake-root.md) 同步修訂：[01-requirements](../01-requirements.md) 第 9 條「全部寫入資料庫」、[04-deployment](../04-deployment.md)「收件根目錄以唯讀掛載給 Engine」。回答：最後的字幕檔如何產出、放在哪裡、如何命名、如何避免半成品與越界寫入。

## 背景

目前結果只在 SQLite 的 `result` 表（來源語言 SRT、繁體中文 SRT），要播放須自行導出（runbook 第 9 節）。使用者要求產出字幕檔並放在影片旁邊，名稱為「影片檔名_語系.srt」。收件根目錄目前以唯讀掛載給 Engine（04）。

## 選項

| 選項 | 優點 | 缺點 | 結論 |
|---|---|---|---|
| A. pipeline 在最後階段直接寫檔 | 單一產物、無額外元件；路徑檢查已在 pipeline 內 | 收件根目錄須可寫；寫入範圍由 pipeline 自己負責 | 採用 |
| B. 另做搬運程式從資料庫導出 | pipeline 保持唯讀 | 多一個元件與排程；要知道影片位置與語系 | 否決 |
| C. 透過 Engine 的 file 資源寫入 | 受 Engine 檔案範圍保護 | `file` 資源只對應單一檔案（ADR-037 背景），目標檔名隨 run 變化 | 否決 |

## 決策

**產出。** 最後新增階段 `export`（第 12 階段），在 `translate` 之後寫出兩個檔案；資料庫的 `result` 仍是完整紀錄，檔案是其副本，檔案內容與 `result` 的 SRT 文字逐位元組相同，UTF-8、無 BOM。

**位置與檔名。**

- 目錄與請求的影片檔相同。檔名為「影片檔名去掉最後一個副檔名，加底線、語系、`.srt`」。例如 `movie.mp4` 得 `movie_en.srt` 與 `movie_zh-TW.srt`；`a.b.mp4` 得 `a.b_en.srt`。
- 來源語言字幕的語系取自摘要階段判定的語言碼，正規化為小寫的主語言碼（兩到三個英文字母，區域與文字變體丟棄，例如 `en-US` 得 `en`）；缺少（摘要降級）或無法辨識時為 `und`。
- 繁體中文字幕的語系固定為 `zh-TW`。來源語言為中文時來源檔為 `zh`，兩個檔名不會相同。

**安全。**

- 寫入範圍只限「請求的影片檔所在目錄」，且該目錄解析後（含符號連結）必須在收件根目錄之內；輸出檔名只由上述規則組成，不含呼叫端提供的其他字元。
- 目標檔已存在且不是一般檔案（目錄、符號連結）時拒絕寫入。
- 提早失敗：`intake` 階段就檢查該目錄可寫、兩個目標檔名可用，不等到數小時後。

**一致性。**

- 兩個檔案先寫成同目錄下的暫存檔，再各自以原子換名置換；已存在的同名一般檔案被覆蓋（重送 webhook 即重做）。兩個換名都成功才算完成；第二個失敗時移除第一個剛寫的檔。
- 寫出失敗使 run 失敗，原因為專用的分類，訊息不含根目錄的絕對路徑；資料庫的 `result` 已保存，管理員可用 runbook 的導出方式取回。
- 降級（`success-degraded`）的 run 照常寫出檔案。run 被取消或失敗於 `export` 之前時不寫任何檔案。

## 取捨

- 得到：字幕直接可被播放器使用；沒有額外元件。
- 失去：Engine 的帳號對收件目錄有寫入權限（收件根目錄不再唯讀）；任何有權限呼叫 webhook 的人能讓 pipeline 在收件根目錄內建立或覆蓋 `.srt` 檔（範圍已限制在影片所在目錄與固定檔名規則）。
- 外部風險：若呼叫端以「新檔出現」觸發 webhook，新建的 `.srt` 不得再觸發；這由呼叫端負責，記載於部署文件。

## 後果

- 新增階段使階段表由 11 變為 12；`result` 與其他資料不變。
- 部署檔與文件由 [WI-1421](../work-items/WI-1421-writable-intake-root.md) 處理；pipeline 行為由 [WI-1420](../work-items/WI-1420-subtitle-export.md) 處理。
