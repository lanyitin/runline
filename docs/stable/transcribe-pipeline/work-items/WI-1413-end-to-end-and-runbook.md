# WI-1413 端到端驗證與管理員上線手冊

狀態：已核可（2026-10-11），未開始。儲存庫：T（手冊）與 R（若需修正文件）。相依：WI-1400、WI-1402、WI-1412、WI-1416。

## 驗收條件

1. 在含 WI-1402 環境的真實 Engine 上：上傳 pipeline、管理員允許 unsafe、建立資源與綁定、建立 webhook trigger（呼叫端提供參數為 `file`）；以 webhook 帶入收件目錄下的樣本影片，完成整條流程，可從資料庫取回兩份 SRT 與摘要。
2. 以短（約 1 分鐘）與長（至少 30 分鐘）影片各一，記錄每階段耗時、呼叫次數、降級數，修正 [07](../07-nfr-risks.md) 的容量估算。
3. 負向案例：帶入根目錄外的檔名、不存在的檔名、無音訊檔案，皆被拒絕或失敗且原因明確；錯誤密鑰與重複 delivery 的行為符合 ADR-036。
4. 取消中途的 run：行程與工作目錄被清理，已完成階段的資料保留。
5. 對真實 Lemonade 的驗證（模型 id、圖片輸入、遵守率）由使用者在有服務的環境執行，結果寫入報告；未執行者標記「未驗證」。
6. 手冊涵蓋：主機需求、設定、資源與 trigger 建立、第一次執行、查詢結果的方式、降級的意義、排錯，以及與 digest-rss 共用 Lemonade 時的排程建議。手冊放在 draft，核可後晉升。

## 架構約束

不新增功能；發現缺陷時回報為新的工作項，不在本項內擴張範圍。
