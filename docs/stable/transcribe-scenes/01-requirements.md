# 1 需求

狀態：已核可（2026-10-16）。本文回答：這次修訂要達成什麼、範圍到哪裡、怎麼算成功，以及還有哪些未決問題。

## 目標與角色

- **觀看者**：讀字幕的人。要能讀懂內容、看得出是兩人對話還是一人獨白。
- **管理員**：部署與設定 pipeline 的人。要能以參數調整片段長度、場景切分、破折號顯示、二次轉錄，並從紀錄判斷品質與耗時。

## 核心情境

1. cron 或 webhook 觸發，pipeline 處理一部影片，在影片旁寫出來源語言與繁體中文兩份 SRT，並在資料庫留下摘要。
2. 管理員關閉破折號參數後重跑輸出：SRT 不再出現破折號，其他內容相同。
3. 首次轉錄把日語音訊輸出成中文的片段，由第二個轉錄模型補救，字幕不再出現中文垃圾句。

## 功能需求

1. **長片段轉錄**：轉錄模型每次聽約 30 秒（可調）的音訊；片段連續覆蓋整條時間軸，切點落在最安靜的位置；整段沒有語音的片段不送轉錄。
2. **二次轉錄**：首次轉錄降級（截斷、失敗、低資訊量）、或文字的語言與影片不符的片段，以第二個轉錄模型在固定語言下再轉錄一次；採用規則擋下低資訊量、語言不符與幻覺句。預設開啟，預設模型為 Kotoba-Whisper（日語專用）；影片語言不在清單內（預設只有日語）時略過；參數留空即關閉。
3. **強制對齊**：每個片段的轉錄文字以 Qwen3-ForcedAligner 取得字詞的起訖時間。
4. **組成字幕條目**：由程式依標點、停頓與長度原則（每條不超過約 6 秒、有最短顯示時間與每行字數上限）把字詞組成條目。組成後條目的數量與時間固定。
5. **場景**：依畫面變化切出場景；超過約 12 秒（可調）的場景依條目邊界切成接近 12 秒的場景片段。
6. **潤飾**：以場景片段為單位，附該片段的畫面（每秒一張，有上限）與前一片段的唯讀語境；修正轉錄錯誤，並標出每一行是否為新說話者的開頭。
7. **換人的呈現**：參數控制 SRT 是否在新說話者的行首畫出對話破折號，預設畫出；前一條是另一人時，這一條的第一行也畫。來源語言與繁體中文兩份 SRT 的換人位置一致。
8. **摘要**（一律以英文撰寫）：
   - 每個場景片段描述誰在場（以描述性稱呼）、在做什麼、情緒、場所；沒有對白的片段也依畫面描述；
   - 每個場景彙整其片段；
   - 全片摘要依主題或段落組織，不逐條流水帳，不列角色表。
9. **翻譯**：以場景片段為單位翻成繁體中文，附該場景摘要與已翻好的前文；保持條目、行與換人資料不變。
10. **刪除畫面核對階段**。
11. **輸出時不再合併短條目**（長度原則在組成條目時已處理）。

## 非功能需求

- **準確度優先**：可調的成本旋鈕不得降低文字層的要求（條目、行、時間、換人的契約）。
- **處理時間目標**：一小時影片 3 小時內完成（軟性目標，不設成逾時）。
- **可觀測**：每次模型呼叫記錄提示、回答、推理內容的長度、耗時、token、結束原因；每個階段記錄計數與耗時。
- **及早止損**：同一階段因同一原因連續失敗時，在數分鐘內停止，而不是耗盡數小時。
- **不保存影像與音訊**：沿用現行原則，畫面只在記憶體中。

## 範圍

- 範圍內：上述功能；依文字與畫面推斷換人。
- 範圍外：聲紋辨識、標出說話者是誰（A／B 或名字）、辨識角色名字、中斷後續跑、影片上傳。

## 成功指標

| 指標 | 量測方式 |
|---|---|
| 轉錄品質不低於現行 | 同一部影片人工抽查至少 30 條，錯字與斷句錯誤數不高於現行版本 |
| 二次轉錄的效果 | 人工聽測二次轉錄被採用的片段，確認文字比首次轉錄更接近實際；中文垃圾句的數量低於關閉時 |
| 字幕長度 | 超過 6 秒的條目為 0；短於最短顯示時間的條目為 0 |
| 換人可辨識 | 人工抽查至少 3 個對話場景與 1 個獨白場景，換人標記的正確率由使用者判定可接受 |
| 處理時間 | 一小時影片的總耗時，與 3 小時目標比較並記錄 |
| 止損 | 人為造成某階段全部失敗時，該階段在 10 次呼叫內停止 |

## 假設

1. Qwen3-ForcedAligner 能在 Lemonade 主機的 GPU 上，經 llm-gateway 以可接受的速度處理 30 秒片段（WI-1451 驗證，[ADR-056](adr/ADR-056-alignment-on-gateway-gpu.md)）。
2. Lemonade 接受 30 秒 WAV 的轉錄請求，大小在資源的 `maxRequestBytes` 之內（WI-1452 驗證）。
3. gemma4 在 thinking 關閉時，能依畫面與文字合理標出換人（WI-1452 抽樣驗證）。
4. 影片有畫面；沒有畫面的影片整部視為一個場景，潤飾與摘要不附圖。
5. Lemonade 主機已註冊 Kotoba-Whisper 模型（[ADR-075](adr/ADR-075-second-pass-default-on-with-kotoba.md)）；缺少時略過二次轉錄，不使 run 失敗。

## 待確認問題

- 二次轉錄預設開啟的品質：待使用者人工聽測（見 ADR-075）。影響：結果不佳時把預設改回關閉。
- 沒有對白的片段也做摘要，所增加的呼叫成本由 WI-1452 量測；超出 3 小時目標時，依 [07](07-nfr-risks.md) 的旋鈕調整，不取消這些摘要。
