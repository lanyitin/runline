# WI-1459 翻譯附角色表、場景摘要與前文，保留行與換人

本文回答：翻譯以什麼為語境、回答要守住哪些契約。狀態：已核可（2026-10-14）。相依：WI-1458。決策見 [ADR-054](../adr/ADR-054-scene-summaries-and-translation-context.md)。儲存庫：T。

## 行為與驗收條件

1. **請求**：每個有條目的場景片段一次請求，附：
   - 角色表（含譯名）；
   - 該場景的摘要；
   - 前一片段已翻好的譯文作為唯讀語境；
   - 該片段的條目（含行與換人標記）。
2. **譯名**：角色的譯名在第一次出現時確定並寫入 CHARACTER，之後的片段沿用；同一 run 內同一角色的譯名一致。
3. **回答契約**：
   - 條目數、序號、時間不變；
   - 每條的行數與每行的換人標記與來源相同；
   - 只用繁體字（沿用現行的簡體檢查）；
   - 語境內容不得出現在回答中。

   違反者重試，重試用盡則該片段保留來源語言文字，計入降級。
4. **來源已是繁體中文**的片段不送請求，直接採用潤飾後文字，不算降級（沿用現行規則）。
5. **輸出**：中文 SRT 的換人位置與來源語言 SRT 一致（同一份換人資料），依 `subtitleDialogueDash` 畫出。
6. **缺摘要時**照常翻譯，不附缺少的部分。
7. **紀錄**：ENTRY_LINE（翻譯階段）依 [06](../06-data-model.md) 寫入；log 的結果行列出片段數、送出數、降級數、略過（已是繁體中文）數。

## 架構約束

- 翻譯不改條目、時間與換人資料。
- 兩份 SRT 由同一個函式畫出。
- 嚴格 TDD；測試不使用 Stub 或 Mock。
