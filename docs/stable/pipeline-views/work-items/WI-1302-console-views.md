# WI-1302 Console 的通用 view 呈現

本文回答：Console 如何顯示 pipeline 宣告的 view。狀態：已核可（2026-10-11）。相依：WI-1301。儲存庫：runline。

## 背景

見 [ADR-033](../adr/ADR-033-pipeline-views.md)「呈現」。Console 沿用 ADR-015、ADR-017 與 WI-33 的骨架、多語系與不可信內容機制。

## 行為與驗收條件

1. pipeline 詳情頁有「資料」區，列出該版本的 view（標題、說明、可否執行的狀態）。沒有宣告 view 的 pipeline 不顯示此區。管理員有多位上傳者時，先選上傳者（同綁定畫面）。
2. 選一個 view：依參數定義顯示輸入（文字、整數、固定選項的選單；必填標示），送出後顯示表格與分頁（下一頁、上一頁；有「還有更多」才能下一頁）。
3. 「狀態」欄依宣告的語氣以顏色加文字呈現，不只靠顏色（可及性）。時間欄以使用者的語言與時區格式顯示。
4. 鑽取：宣告了鑽取的欄位可點選，開啟目標 view 並帶入對應參數；返回上一個 view 時保留原參數與頁碼。
5. 所有儲存格值當純文字顯示，不解譯標記、不產生連結；以含標記字元的資料驗證。
6. 各種錯誤（未綁定、停用、逾時、結構不符、忙碌、無權限）有可讀的說明與重試方式，不顯示 JSON；用 zh-TW 與 en 兩種語言。
7. 開發人員與管理員的可見範圍與 API 一致；開發人員看不到他人的 view。
8. 契約測試在 Fake 與真實 Engine 上通過（沿用既有 Console 契約測試方式）。

## 架構約束

- 只用同源相對路徑呼叫 API，不引入第三方腳本或字型；不新增頂層導覽。
- view 的標題與欄位標籤是 pipeline 提供的單一語言文字，原樣顯示；固定介面文字走多語系。
