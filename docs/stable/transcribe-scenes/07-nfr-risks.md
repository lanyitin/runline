# 7 非功能性考量與風險

狀態：已核可（2026-10-15）。本文回答：新流程的處理時間是否落在目標內、超出時怎麼調、失敗時怎麼表現，以及主要風險。數字來自 [ADR-058](adr/ADR-058-measured-defaults.md) 與兩份量測報告（[WI-1451](../../draft/transcribe-scenes/WI-1451-forced-alignment-report.md)、[WI-1452](../../draft/transcribe-scenes/WI-1452-long-chunks-and-segments-report.md)）。

## 處理時間目標

一小時影片 3 小時內完成。這是軟性目標，用來決定預設值，不設成逾時；準確度優先。

## 容量（一小時影片，實測推算）

| 階段 | 次數 | 實測單次耗時 | 小計 |
|---|---|---|---|
| 擷取、降噪、VAD、切段 | 1 | 約 13 分（run 8，保守不下調） | 約 13 分 |
| 轉錄（長片段） | 約 114 | 中位數 0.5 秒，第一個請求 6.3 秒 | 約 1.5 分 |
| 對齊（gateway GPU） | 約 120 | 中位數 0.07 秒；切到對齊約 4 至 5 秒 | 約 1 分，加兩次切換約 13 秒 |
| 場景偵測 | 1 | 約 2.4 分（8 vCPU） | 約 2.4 分 |
| 潤飾（附 4 至 8 張圖） | 約 300 | 中位數 3.9 至 4.9 秒 | 約 21 至 25 分 |
| 片段摘要（附圖） | 約 300 | 中位數 2.2 至 3.1 秒 | 約 11 至 16 分 |
| 翻譯 | 約 300 | 中位數 2.7 秒 | 約 11.6 分 |

合計約 64 至 69 分鐘，遠低於 3 小時。量測為 run 8 的一段 10 分鐘外推，不是整部一小時影片的實跑；整部實跑以部署後的測試 run 與成品核對為準。

**超出目標時的旋鈕**（依序使用，都不降低文字層的契約）：

1. `framesPerSegment`：每個片段的圖片數上限（預設 4）。
2. `segmentTargetSeconds`：場景片段長度（預設 12）。
3. 片段摘要與潤飾共用同一次請求（[03](03-options.md) 選項 F2）。

## 失敗模式與降級

| 情況 | 表現 |
|---|---|
| 某個長片段轉錄失敗（重試用盡） | 該片段沒有字幕（`chunk.text` 為空值），計入降級與 `transcribeFailed`；run 繼續 |
| 某個長片段被生成上限截斷 | 不重試、不計入及早止損，該片段降級；有語音的片段全部沒有文字時 run 以 `NO_TRANSCRIPT` 失敗（[ADR-059](adr/ADR-059-truncated-chunk-is-content-not-outage.md)） |
| 對齊失敗 | 該片段的文字依字數比例分配到片段時間內，標為估計時間（`chunk.alignment = estimated`），計入降級與 `alignFailed` |
| 場景偵測失敗 | 整部影片視為一個場景，計入降級並記錄原因 |
| 影片沒有畫面 | 整部影片為一個場景，不計降級；潤飾與摘要不附圖 |
| 潤飾、翻譯的某片段失敗 | 保留上一階段文字（翻譯則保留來源語言），該片段沒有換人標記，計入降級 |
| 摘要失敗 | 對應層缺摘要，上一層以現有內容彙整，每份缺漏計一次降級 |
| 同一階段因同一原因連續失敗（及早止損） | run 在達到 `earlyStopFailures` 時以 `EARLY_STOP` 失敗，分類指出階段與原因（[ADR-055](adr/ADR-055-thinking-policy-and-early-stop.md)） |
| gateway 無法取得 GPU（503）或停止 | 對齊重試用盡後依上列降級；gateway 停止時所有 LLM 類 pipeline 都無法呼叫模型（[ADR-056](adr/ADR-056-alignment-on-gateway-gpu.md)） |
| Engine 資源的 `allowedModels` 有設定但缺少對齊模型 | 第一個對齊請求以設定類失敗結束 |

## 可觀測性

- 階段結果行與 RUN SUMMARY 含片段數、無語音數、轉錄失敗數（含截斷、逾時、其他的分項）、對齊失敗數、對齊耗時、第一個對齊請求耗時、場景數、場景片段數與長度、場景偵測耗時、推理 token 總數、各階段耗時。
- EXCHANGE 記錄推理內容、上游 HTTP 狀態與結束原因（[06](06-data-model.md)）；對齊請求同樣記入。
- Console view 可查場景、條目（含時間來源是對齊或估計）、降級、摘要與角色表。

## 安全

- 畫面與音訊只在記憶體與工作目錄，不進資料庫與 log（沿用）。
- 對齊在 Lemonade 主機的 gateway 上執行；模型版本與檔案雜湊在 gateway 固定，執行時不連網下載。
- gateway 沒有認證並綁在 `0.0.0.0`，對齊端點與其他端點同樣暴露在區網（沿用現況，ADR-056 已列為取捨）。

## 風險

| 風險 | 影響 | 緩解 |
|---|---|---|
| 對齊在雜音、喘息、多人重疊時不準 | 字幕時間偏移 | 失敗時有估計時間的退路；時間精度在成品字幕核對時抽查 |
| 30 秒片段中的非語音段引發 ASR 幻覺或重複輸出 | 字幕出現不存在的句子，或片段被截斷 | 整段無語音的片段不送；生成上限截斷後該片段降級；成品核對時抽查 |
| 場景偵測對運鏡、光線誤切或漏切 | 片段邊界不自然 | 門檻與最短場景長度可調；片段內附前一片段的語境 |
| LLM 誤判換人 | 讀者被錯誤的破折號誤導 | 破折號可關閉（`subtitleDialogueDash`）；換人資料可查 |
| 譯名只在模型寫出 `NAMES:` 時才確定 | 同一角色譯名前後不一致 | 未命名的角色在下一個片段再提供；成品核對時抽查 |
| 附圖請求耗時超出估計 | 超過 3 小時目標 | 上方的旋鈕 |
| 長期獨佔 Lemonade | digest-rss 等候 | 沿用現行的排程建議（stable runbook 第 14 節）；每個 run 只切換 GPU 兩次 |
| 筆電獨顯休眠或驅動不可用 | 對齊失敗，全部片段改用估計時間 | 在 Lemonade 主機處理；降級計入並可從 view 查出 |
