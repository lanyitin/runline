# WI-1410 依 VAD-A 分組潤飾

狀態：已核可（2026-10-11），未開始。儲存庫：T。相依：WI-1409。規則見 [ADR-038](../adr/ADR-038-segment-model-and-stage-invariants.md) 第 3、4 點。

## 驗收條件

1. 每個 VAD-A 組把其下 VAD-B 條目（序號、時間、轉錄文字）以 SRT 形式送 gemma4；模型與請求參數可由 pipeline 參數控制（含此階段的覆寫）。
2. 提示要求只修正因句子被切斷而生的轉錄錯誤，不改變條目數、順序與時間；提示內容的規範寫在專案文件。
3. 回答經解析並驗證：條目數、順序、時間與輸入相同才採用，結果寫入潤飾欄位。
4. 回答格式錯誤或違反不變式：依參數重試；用盡後該組採用轉錄文字（降級），計入降級數並記錄原因。
5. 全部條目為「無語音」的組不送出請求。
6. 每次呼叫寫入模型對話紀錄（提示、回答、耗時、模型 id）。
7. 以真實 Engine 資源路徑與自製的簡易真實對話服務測試，服務需能刻意回傳違反不變式的回答。

## 架構約束

階段在所有轉錄完成後才開始（模型分批）；不改變時間。
