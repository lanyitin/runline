# ADR-073 降級或語言不符的片段，以 Whisper 在固定語言下二次轉錄

本文回答：轉錄結果降級、或語言與影片不符的長片段，如何以第二個轉錄模型補救，觸發條件、採用規則與邊界是什麼。狀態：已核可（2026-10-16）；決策 2、7 已被 [ADR-075](ADR-075-second-pass-default-on-with-kotoba.md) 取代。補充 [ADR-059](ADR-059-truncated-chunk-is-content-not-outage.md)、[ADR-062](ADR-062-low-information-transcript-is-not-subtitle.md)、[ADR-057](ADR-057-asr-endpoints-and-alignment-word-timing.md)，不取代任何決策。

## 背景

在一支日語影片（run 43，115 個長片段）的量測：

| 觀察 | 數據 |
|---|---|
| Qwen3-ASR 對日語音訊輸出中文 | 202 條字幕中 89 條不含假名；扣除語助詞後約 37 條（約 18%）是中文句子 |
| Qwen 把內容翻成中文而非轉錄 | 一個片段 Qwen 為中文句子，Whisper 為對應的日語句子，語意相同 |
| 降級的片段 | 14 個問題片段中，Whisper 在固定日語下約 9 個給出可讀的日語句子，5 個仍無實質內容 |
| 正常片段 | 10 個正常對話片段，Whisper 與 Qwen 有 8 個大意一致 |
| Whisper 的語言自動偵測 | 正常片段機率 0.98 至 1.00；低資訊量或短片段會誤判為韓文或英文（機率 0.29 至 0.70） |
| Whisper 的缺陷 | 結尾出現固定的幻覺句（例如日語的「感謝收看」）、短句重複、偶有非日文雜訊 |
| 成本 | 每個約 30 秒的片段 0.2 至 3.1 秒；Whisper 與 Lemonade 的 llm 槽分開；冷載入約 6 秒 |

依據是單一影片的 27 個片段，沒有人工聽測的標準答案；「更準」的判斷來自語言一致與語意對應。

Qwen3-ASR 走 chat 端點，`asrLanguage` 在該路徑無法生效（[ADR-062](ADR-062-low-information-transcript-is-not-subtitle.md) 的不採用說明）；Whisper 走 transcriptions 端點，`language` 欄位有效，且 Engine 資源放行該欄位（[ADR-057](ADR-057-asr-endpoints-and-alignment-word-timing.md) 背景）。

## 決策

1. **二次轉錄的時機**：全部片段的第一次轉錄完成後、對齊之前，對符合觸發條件的片段以第二個轉錄模型再轉錄一次。不改變第一次轉錄的流程與參數。
2. **執行語言（run 語言）**：
   - 呼叫端提供語言參數時，以它為準；
   - 否則，由第二個模型對有語音的片段取樣自動偵測，在機率不低於門檻的結果中取多數；
   - 取得不到可靠的 run 語言時，不做二次轉錄，log 說明原因。
3. **觸發條件**（任一成立）：
   - 第一次轉錄降級：被截斷、失敗、或判為低資訊量（[ADR-062](ADR-062-low-information-transcript-is-not-subtitle.md)）；
   - 第一次轉錄的文字與 run 語言不符：以文字的書寫系統判定，不依賴詞典；只含語助詞或擬聲的文字不算不符。
4. **二次轉錄的請求**：語言固定為 run 語言，不用單一片段的自動偵測。生成上限不適用（沿用 [ADR-057](ADR-057-asr-endpoints-and-alignment-word-timing.md) 決策 1），只受呼叫逾時保護。
5. **採用規則**：二次轉錄的文字同時滿足下列條件才採用，否則維持第一次轉錄的結果與降級原因：
   - 不是低資訊量；
   - 文字與 run 語言相符；
   - 去除結尾的固定幻覺句後仍有文字。幻覺句清單是參數，預設含量測到的日語句。
6. **採用後的處理**：被採用的文字取代該片段的轉錄文字，其後的對齊、場景、潤飾、摘要、翻譯與第一次轉錄的文字相同；片段記錄文字來自哪個模型，並保留第一次轉錄的文字供稽核。被救回的片段不計入降級與 `transcribeFailed`。
7. **預設關閉**：第二個轉錄模型為參數，空值表示不做二次轉錄；預設值待人工驗證後再決定（待確認問題）。
8. **不使用 d1 判定**：觸發條件只用決策 3 的規則，不呼叫 LLM。d1-3b 的量測（34 個有語音的片段，其中 16 個需要重轉錄）：
   - 單條字幕判定：誤判率約 29%，已知問題 10 條只抓到 6 條；
   - 以片段為單位，加前後文、判斷依據、文字特徵的五種輸入：召回率 0.25 至 0.38，誤判率 0.39 至 0.72，加入前後文與判斷依據沒有改善；
   - 語言通順度評分（告知語言為日語，請 d1 以 10 級量表給 0 至 100 分，分數換算為機率加權期望值）：分數集中在 38 至 58 的窄帶，對標準答案的 AUC 為 0.77（只給文字）與 0.82（加前後文）；作為對照的 Whisper 日語文字，分數與 Qwen 的垃圾文字沒有區別（AUC 0.43，中位數約 51）。需要與不需要兩組的分數範圍重疊，單一門檻在 34 個片段上的間距只有約 2 分，且門檻由同一批資料選出；
   - 評分的校準（自備的正常日語句 80 條，與 7 種破壞後的句子各 20 條）：正常句的中位數 63 至 76，打亂字元 41、隨機假名 36、語意不通 51、日中混合 50、中文翻譯 54，正常對破壞的 AUC 為 0.88；英文翻譯（60）與同句重複 5 次（64）分不開（AUC 0.78、0.68）；分數隨字數上升（同類內相關係數最高 0.67），極短的正常回應從 26 到 87；宣告為中文時，同樣的中文文字的中位數從 54 升到 68。實際片段（30 秒的多句轉錄、含語助詞）的分數落在 38 至 58，低於正常句的中位數，且正常與需要重轉錄的片段重疊，因此分數的含義不能由乾淨句子的校準推到真實的轉錄文字；
   - 純規則（文字不含假名且有 2 個以上非語助詞的漢字）：召回率 0.56，誤判率 0.22；其漏判的 7 個片段都是第一次轉錄為空或為日語的降級片段，由決策 3 的降級條件觸發。
9. **可觀測**：結果行與 RUN SUMMARY 列出觸發的片段數（依觸發原因）、採用數、未採用數（依原因：低資訊量、語言不符、幻覺句後無文字、呼叫失敗）。

## 取捨

- 得到：
  - 救回被 Qwen 輸出成中文的日語片段，這是這支影片最大的品質問題；
  - 觸發條件不需 LLM，成本只有觸發片段的 Whisper 呼叫；
  - 固定語言避免 Whisper 在低資訊量片段誤判成韓文或英文。
- 失去：
  - 多一個模型與一個參數；
  - 「語言不符」只抓得到中文類的錯誤，抓不到同為日語但聽錯的字；
  - Whisper 仍有結尾幻覺與短句重複；清單只涵蓋量測到的句子，重複不另行去除；
  - 無語言參數的影片依賴取樣偵測，混語影片的 run 語言可能不準。
- 不採用：
  - 以 d1 判定：量測結果見決策 8，召回率低於純規則、誤判率高於純規則，且多一個模型呼叫。
  - 全部片段改用 Whisper：品質需要人工聽測驗證，改動範圍也較大；先以觸發式補救。
  - 只重做降級片段：救不回「通順但是錯語言」的片段，它們在量測中不是降級。

## 後果

- 新工作項 [WI-1481](../work-items/WI-1481-whisper-second-pass.md)。
- 新參數：第二個轉錄模型、run 語言、取樣偵測的機率門檻與取樣數、幻覺句清單。
- 05 的 IPC 表多一列「第二個轉錄模型：`audio.transcriptions`」；Lemonade 主機的部署多載入 Whisper（只在觸發時載入）。
- 對齊使用 run 語言。

## 待確認問題

- 預設是否開啟：需要人工聽測 B、C 組片段，確認 Whisper 比 Qwen 更接近實際。影響：預設開啟但品質較差，會改壞原本可用的片段（採用規則只擋語言與低資訊量，不擋同語言的錯字）。
- 第二個轉錄模型的建議值：Whisper-Large-v3-Turbo（多語）或 Kotoba-Whisper-v2.0（日語專用，Lemonade 的自訂模型）。在 34 個片段上，Kotoba 的結尾幻覺句 0 次（Turbo 3 次）、非日文雜訊 0 個片段（Turbo 3 個）、短句重複 6 個片段（Turbo 13 個），中位耗時 0.35 秒（Turbo 約 1 秒）；以寬鬆規則計算的 14 個降級片段中可讀日語數為 11（Turbo 13）。沒有人工聽測，不能判定哪個更接近實際。Kotoba 只支援日語，非日語影片須用多語模型，故模型維持為參數。
- 語言不符的判定細則（語助詞的範圍、判為不符所需的字數）：量測的規則基準（無假名且有 2 個以上非語助詞漢字）在 34 個片段中誤觸發 4 個（Qwen 為中文，Whisper 為短句如「おいしい」）；這類誤觸發只多一次 Whisper 呼叫，採用規則決定是否取代。標準答案由規則與 Whisper 結果推得，不是人工聽測。
- 取樣偵測的取樣數與門檻預設值。
- 對齊模型是否接受 Whisper 轉出的文字：需要實機驗證，列入 WI-1481。
