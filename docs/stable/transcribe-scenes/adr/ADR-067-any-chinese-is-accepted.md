# ADR-067 翻譯接受任何中文字形，語境檢查不誤判短句

本文回答：翻譯回答的字形檢查是否還需要，以及與語境重複的檢查如何避免誤判。狀態：已核可（2026-10-15）。修改 [WI-1459](../work-items/WI-1459-translation-with-context.md) 條件 3 的「只用繁體字」與 [ADR-064](ADR-064-answer-contract-violations-are-per-segment.md) 決策 3 中「簡體字檢查只對沒有假名的行做」。

## 背景

- 使用者的需求是「只要是中文都可以」，不要求回答一定是繁體字。
- 簡體字檢查在實機 run 造成誤判與浪費：
  - 簡體專用字集誤收了繁體也使用的字（「概」），讓正確的翻譯「大概吧」被判作廢；
  - 日文新字體漢字（「国」「学」）與字集重疊，讓原樣回傳的日文被歸為簡體，掩蓋了真正的原因；
  - 該檢查在 run 19 的降級片段中佔 3 個片段、16 條，其中至少一個確定是誤判。
- 語境重複檢查（`CONTEXT_RETURNED`）把「與前一片段某條譯文相同的短句」當成模型把語境抄回來。實機 seg 102：「テカっています。」正確地譯成「亮亮的。」，前一條「テカテカ。」的譯文剛好也是「亮亮的。」，三次重試都被判違規，條目退回日文。

## 決策

1. **取消簡體字檢查**：翻譯回答不再檢查字形；繁體、簡體、混用都接受。`SIMPLIFIED_CHARACTERS` 這個失敗原因移除；譯名（`NAMES:`）的字形檢查一併取消。
2. **仍保留未翻譯的判定**：回答的行含假名視為未翻譯（`UNTRANSLATED`，ADR-064 決策 3），不受本 ADR 影響。
3. **語境重複檢查改為比對來源**：只在回答「重複語境的內容」時判違規，也就是回答中的條目與語境的**來源文字**相同或語境的譯文**連同來源**一起出現；一條回答只因為文字與語境的譯文相同，而它的來源文字與語境的來源文字不同時，不判違規。語境完全被當成條目回傳（條目數、序號對不上）仍由既有的結構檢查處理。
4. **提示詞**：預設 `translateSystemPrompt` 不再要求「只用繁體字」，改為「用中文」；繁體偏好可由使用者自行覆寫提示詞。
5. 此項只涉及翻譯；摘要、潤飾不受影響。

## 取捨

- 得到：不再因字形誤判而退回原文；少一條會誤殺的規則；失敗原因更單純，真正的未翻譯不會被誤歸類。
- 失去：輸出可能夾雜簡體與繁體字，閱讀時不一致；使用者需要繁體時須自行覆寫提示詞或事後轉換。這是使用者的明確選擇。
- 不採用：修正簡體字集的內容。字集的維護成本與誤判風險長期存在，而需求本身並不需要。
