# WI-1013 Console 的 pipeline 資源綁定設定

本文回答：Console 如何讓使用者選擇各資源角色要注入哪個資源。狀態：已核可（2026-10-08）。

目標：開發人員與管理員在 pipeline 設定介面選擇各資源角色要注入哪個資源。決策見 [ADR-025](../adr/ADR-025-resource-roles-and-binding.md)。工作儲存庫：runline。

## 驗收條件

1. pipeline 詳情頁列出每個資源角色：名稱、型別、用途、目前綁定與資源狀態（存在、停用、型別是否相符），以及是否為同名預設。管理員在同一 pipeline 有多位上傳者時，先選擇上傳者再顯示該上傳者的綁定；開發人員只看到自己的。
2. 每個角色有以型別過濾的資源選單，只列出型別相符的既有資源；可選擇、更換與解除綁定；儲存後顯示結果與錯誤。
3. 未綁定且無同名資源的角色明確標示，並說明該 pipeline 目前不能建立 run；建立 run 因資源問題被拒絕時，畫面導向對應角色。
4. 開發人員與管理員皆可操作；管理員專屬的資源建立與刪除入口不因此對開發人員開放。
5. 資源頁的宣告者顯示改為綁定或同名引用它的 pipeline 與角色，管理員另見上傳者；含連結。
6. 資源選單的選項與型別資訊取自 Engine 的型別目錄與資源 API，不在前端保留複本（ADR-021）。
7. 用途文字是不可信內容，以既有的不可信內容顯示機制處理（WI-33、WI-37）；zh-TW 與 en 的文案齊備。
8. 以真實瀏覽器腳本驗證主要流程：綁定、更換、解除、型別不符不可選、停用資源的標示、管理員選擇上傳者。

## 架構約束

- 只用同源 `/api/v1`，不改變 Bearer API 契約（ADR-012、ADR-015）。
- 不新增前端對資源型別的硬編碼。
