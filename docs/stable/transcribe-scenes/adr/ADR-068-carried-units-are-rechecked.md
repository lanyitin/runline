# ADR-068 續跑時用現行規則重新檢查被沿用的單位

本文回答：續跑的起點階段中，已被舊規則判為「成功」的單位，是否要用現行規則再檢查一次。狀態：已核可（2026-10-15）。補充 [ADR-063](ADR-063-resume-run-from-stage.md) 決策 3 與 [ADR-066](ADR-066-degraded-run-can-be-resumed.md) 決策 2、3。

## 背景

- run 19 的翻譯有 104 條條目在判定為成功的片段中原樣回傳，其中含假名的有 42 條。當時的驗證沒有未翻譯的判定。
- 以 translate 為起點續跑 run 19 時，只重送了降級的 20 個片段，158 個「成功」的片段整段沿用，原樣回傳的條目一條也沒有重做；沒翻譯的條目只從 181 降到 142。
- 規則會隨版本變嚴；沿用舊 run 的結果時，應該以現行的規則為準，否則修好的檢查無法補救舊 run。

## 決策

1. **起點階段的沿用單位，沿用前以現行規則再檢查一次**：檢查只用已儲存的文字，不呼叫模型，只套用「僅憑文字即可判定」的規則；不通過的單位視為未完成，與降級的單位一樣重做。
2. **可再檢查的規則（翻譯階段）**：
   - 譯文的行含假名（`UNTRANSLATED`）；
   - 條目的行數與換人標記不符合現行的行數規則；
   - 超過兩行。
   潤飾階段目前沒有僅憑文字即可判定的新規則，行為不變。轉錄與摘要不適用。
3. **粒度**：以條目為單位。片段中通過檢查的條目沿用，不通過的條目重做（與 ADR-066 的部分採用相同的重送方式）。
4. **不重新檢查的**：無法僅憑文字判定的規則（回答的結構、語境重複、截斷）；來源本身沒有假名的條目（例如被標成中文的轉錄文字）；沒有假名的日文漢字條目（無法判定是否未翻譯）。
5. **可觀測**：RUN SUMMARY 與 log 顯示「因現行規則重新檢查而重做的單位數」與按原因的計數，與沿用數、重做數分開列出。

## 取捨

- 得到：舊 run 的未翻譯條目可由續跑補齊；規則修好後不必整個 run 重做。
- 失去：
  - 續跑的重做量增加，翻譯階段的耗時隨之增加；
  - 現行規則若過嚴（誤判），會讓合格的條目被反覆重做；因此重新檢查的規則限於客觀可判定者（假名、行數）。
- 不採用：只重做降級的單位（無法補齊舊驗證放過的條目）；重新檢查需要模型的規則（成本與不確定性高）。
