# WI-1474 摘要與角色表的回答寬鬆解析

本文回答：三層摘要與角色表如何從不守格式的回答中取得可用的內容。狀態：已核可（2026-10-15）。相依：WI-1458、WI-1468（已完成）。決策見 [ADR-069](../adr/ADR-069-accept-what-can-be-used.md)。儲存庫：T。

## 行為與驗收條件

1. **標記尋找**：在回答中尋找 `LANGUAGE:`、`CHARACTERS:`、`SUMMARY:` 標記；標記之前的問候、標記之間的其他文字、程式碼框、重複的標記（取第一個）一律忽略。片段與場景摘要回答裡出現的 `LANGUAGE:`、`CHARACTERS:` 忽略。不再有 `NOT_FORMATTED`、`EXTRA_CONTENT` 使摘要作廢。
2. **語言碼**：`LANGUAGE:` 之後若是語言名稱（Japanese、English 等），以既有的語言名稱對應轉為語言碼；是合法語言碼就直接用；對應不到為 `und`。不再有 `BAD_LANGUAGE`。
3. **角色表**：`CHARACTERS:` 之後逐列解析；符合 `- 名字 | named 或 unnamed | 簡述` 的列採用，其餘列略過；`CHARACTERS:` 同一行後面的文字忽略。不再有 `BAD_CHARACTERS` 使整個全片摘要作廢。
4. **長度**：摘要超過字元上限時截到上限（在字詞邊界），不作廢，不再有 `TOO_LONG`。
5. **英文與否**：只在紀錄與計數標記（摘要主要文字不是英文），不作廢，不重試。
6. **仍視為缺少**：`SUMMARY:` 之後沒有文字（`EMPTY_SUMMARY`）、回答沒有任何標記、回答被截斷且截斷前沒有可取的 `SUMMARY:` 內容；缺少的單位照常顯示為缺少，不重試（見 WI-1475）。回答被截斷但已有 `SUMMARY:` 的內容時，採用這些內容。
7. **角色 kind**：見 WI-1475。
8. **紀錄與文件**：結果行與 RUN SUMMARY 列出各層摘要的缺少數與原因（無標記、空白、截斷）、非英文標記數、被略過的角色列數；README 的驗證表、重試章節與文件測試同步。
9. **重現情境**（假服務與真實資料庫）：
   - 回答有問候與程式碼框，標記齊全：採用標記內的內容；
   - `LANGUAGE: Japanese`：轉為 `ja`；
   - `CHARACTERS:` 有兩列格式正確、一列缺欄位：採用兩列；
   - 摘要超長：截到上限；
   - 摘要主要是中文：採用並標記非英文；
   - 回答被截斷但已有部分 `SUMMARY:` 內容：採用。
10. 其餘行為不變。
