# WI-1206 Console 的使用者與工作階段管理頁

本文回答：管理員如何在 Console 看到 OIDC 使用者並立刻停用或結束其工作階段。狀態：已核可（2026-10-10）。相依：WI-1202、WI-1205。工作儲存庫：runline（console）。

## 驗收條件

1. 管理員導覽新增「使用者」頁（開發人員不可見，直接輸入網址也被擋並導向適當畫面）：列出 OIDC 使用者的名稱、顯示名稱、停用狀態、最近登入、工作階段數。
2. 可停用與啟用使用者（需確認；停用說明會立即結束其所有工作階段並禁止登入）；可檢視某使用者的工作階段並結束單一或全部。操作結果與錯誤（含 403、404、CSRF 失敗）以多語系文字顯示，錯誤代碼經 `consoleApiDocCheck`。
3. 被停用者的 Console 在下一個請求回到登入頁並顯示「工作階段已結束」；再次登入時顯示「已被停用」，不顯示技術細節。已結束工作階段的 401 不帶原因。
4. 使用者名稱、顯示名稱等來自外部的內容一律以純文字渲染（`PlainText`）；不放寬 CSP。
5. 真實 Engine、PostgreSQL、OIDC 提供者與真實瀏覽器引擎的手動腳本（`npm run e2e`）涵蓋：管理員停用開發人員後，開發人員的分頁在下次操作回登入頁且無法再登入；啟用後恢復；開發人員看不到本頁。回報附結果。

## 架構約束

- 只改 Console；API 依 [05-ipc.md](../05-ipc.md)。
- 不新增 CI；不使用 Stub 或 Mock。
