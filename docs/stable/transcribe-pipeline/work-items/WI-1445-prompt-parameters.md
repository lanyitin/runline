# WI-1445 各階段送給模型的 system prompt 做成可指定的參數

本文回答：管理員如何指定 pipeline 各階段送給語言模型（含 ASR 模型）的 system prompt，沒有指定時用什麼。狀態：已核可（2026-10-13）。依據 [WI-1429](WI-1429-asr-endpoint-by-labels.md)。相依：WI-1429、WI-1436。儲存庫：T（runline-transcribe）。顯示預設值的 Console 變更見 [WI-1446](WI-1446-console-long-text-defaults.md)。

## 背景

使用者要能在建立 run 時改寫送給模型的 system prompt，不改就用預設值，且在建立 run 的頁面能看到預設值的全文。Engine 的參數宣告含名稱、是否必填、預設值（文字），建立 run 時套用預設值，run 的參數紀錄含套用後的結果（[08-api](../../pipeline-engine/08-api.md)）；所以「預設值就是現行的 prompt」可由參數機制承載。ASR 的 chat 路徑目前沒有 system prompt（請求只有音訊，WI-1429 的實驗結論是服務忽略文字提示）。homelab-deployer 對 Qwen3-ASR 的語言提示實驗（文字 part、system 訊息、assistant 預填、頂層 `language` 參數）顯示：頂層參數沒有作用；文字與 system 提示會在無人聲的窗口原樣輸出提示文字，並把雜音窗口改成短日語（現有的跨語言過濾因此失效）；預填使雜音變成日語幻覺句；真實日語窗口的辨識沒有改善。因此 ASR 的 system prompt 預設為空，本項只提供機制。

## 行為與驗收條件

1. **涵蓋範圍**：pipeline 每一個送給語言模型的 system prompt 都有對應的參數：潤飾、核對（含畫面觀察的 prompt，若與核對分開則各一個）、摘要（整支影片與各組的兩種 prompt 各一個）、翻譯，以及 chat 型 ASR 的 system prompt。實作者列出完整清單與參數名稱，由架構師核可，寫入入口文件的參數表與 T README。
2. **預設值**：除 ASR 外，參數的預設值就是現行 prompt 的全文，行為與現況完全相同；ASR 的預設為空，請求不含 system 訊息，與現況逐位元相同。參數留空或僅含空白時使用預設值。
3. **替換範圍**：參數替換的是該階段的 system prompt 全文。user 訊息（資料部分）與輸出的解析仍在程式內，不開放。prompt 內有輸出格式標記（如摘要的 `SUMMARY:`、`LANGUAGE:`）時，預設值保留它們；使用者改寫後若模型輸出不符格式，沿用現有的處理（重試、降級、保留前一階段文字），不新增失敗類別。參數說明文字提醒哪些標記是程式解析所需。
4. **ASR 的作用範圍與警語**：只作用於 chat 型端點；VAD 條目與補掃窗口的每一次 ASR 請求都帶同一份。走 `audio.transcriptions` 的 run 不使用它；參數非空時在 log 說明「此端點不使用 system prompt」，不失敗。ASR 參數的說明文字註明上述實驗結果（提示可能被原樣輸出、可能使雜音變成日語），預設應保持空。
5. **限制**：值可含多行與非 ASCII 字元；長度上限由實作者提案（需大於現行最長 prompt 並留餘裕）並寫入文件；超過上限在 intake 階段以 `CONFIGURATION` 失敗並指出參數名稱，不回傳值。
6. **紀錄**：參數值記在 run 的參數紀錄（套用預設值後）；`exchange` 的請求文字（不含音訊）能看出實際使用的 system prompt（全文或雜湊與長度，由實作者提案，沿用現有的遮罩與長度上限規則）；RUN SUMMARY 或啟動 log 標示每個 prompt 是預設或自訂（不印全文）。
7. **單一寫處**：每個 prompt 的預設值只在程式內定義一處，參數宣告的預設值與實際發送使用同一份，不得出現兩份複本。
8. **驗證**：以 Fake OpenAI 伺服器涵蓋：全部留空時所有請求與現況逐位元相同；各參數分別自訂時，只有對應階段的請求改變且內容原樣；ASR 的 VAD 條目與補掃窗口都帶；轉錄端點不送且 log 說明；超過上限；僅空白；多行與非 ASCII；自訂 prompt 使輸出格式不符時走既有的降級；紀錄與 log 可查；參數宣告的預設值等於實際發送的預設 prompt。
9. 對真實 Lemonade 的效果驗證由 arr 上的 run 或 homelab-deployer 的實驗完成。

## 架構約束

- 不改變條目時間不變式（ADR-038 決策 3、4）、不存放音訊。
- 只新增參數與其預設值，不改其他階段的行為與輸出解析。
- 參數值不得被當作密鑰；請求紀錄沿用既有的遮罩與長度上限規則。
- 薄 jar、嚴格 TDD、不使用 Stub 或 Mock。
