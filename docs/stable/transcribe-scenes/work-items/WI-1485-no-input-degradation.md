# WI-1485 沒有素材的片段與場景直接降級

本文回答：沒有字幕也沒有畫面的片段，以及沒有任何可用片段摘要的場景，摘要階段要怎麼處理。狀態：已核可（2026-10-18）。相依：無。決策見 [ADR-080](../adr/ADR-080-summary-degradation-conditions.md) 決策 1、2、5、6。儲存庫：T。

## 行為與驗收條件

1. **沒有素材的片段**：片段沒有字幕，且沒有取得任何畫面時，不呼叫模型；該片段的摘要視為缺少，降級原因記為「沒有輸入」，與其他降級原因可區分。
2. **有素材的片段照常**：
   - 有畫面、沒有字幕：照常呼叫（請求仍帶「這個片段沒有人說話」的字樣，與現行相同）；
   - 有字幕、畫面取得失敗：照常呼叫，只有文字（與現行相同）。
3. **沒有素材的場景**：場景內沒有任何可用的片段摘要（全部缺少）時，不呼叫模型；場景摘要視為缺少，原因記為「沒有輸入」。
4. **下游**：缺少的摘要不附在下一層的輸入；摘要缺少不阻擋翻譯（[ADR-054](../adr/ADR-054-scene-summaries-and-translation-context.md) 決策 7）；全片摘要在有場景摘要可用時照常進行。
5. **及早止損**：上述降級不累計連續失敗，不影響服務層失敗的計數與門檻。
6. **事後可查**：降級的片段與場景保留降級原因，既有的摘要 view 與 HTML 報告能列出哪些單位缺少及原因（舊 run 沒有原因，視為未記錄）。不新增階段計數或警告；缺少的單位仍依現行方式計入降級統計。
7. 其餘行為不變（有素材時的請求、重試、降級、取樣參數）。

## 架構約束

- 不改 Engine；schema 只增不改，既有資料不刪、不改；舊 run 照常讀得出來。
- 嚴格 TDD；測試以假服務重現：無字幕無畫面（不得送出請求）、有畫面無字幕、有字幕無畫面、整個場景的片段皆缺少、降級後翻譯照常、及早止損計數不變。
- 「沒有取得任何畫面」的判斷沿用現行的畫面取得結果，不另行重新抽取。
- 回報時列出新增的降級原因名稱，以及 view 與報告中顯示的位置。
