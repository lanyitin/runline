# ADR-054 三層英文摘要與角色表，翻譯附角色表與場景摘要

本文回答：摘要要描述什麼、用什麼語言、怎麼組織，翻譯拿什麼當語境。狀態：已核可（2026-10-14）；決策 6 中「條目含行與換人標記」與「保持行數與換人標記不變」已被 [ADR-083](ADR-083-entry-is-one-line.md) 取代；決策 4、5 與決策 6 中的角色表已被 [ADR-074](ADR-074-remove-character-table.md) 取代。取代現行以 VAD-A 組為單位的摘要，以及 [ADR-049](../../../stable/transcribe-pipeline/adr/ADR-049-batches-with-read-only-context.md) 中「翻譯不附全片摘要」的決定。

## 背景

使用者要求：
- 摘要說明演員在做什麼、情緒、所處場景；
- 全片摘要列出所有角色（有名字者），且不是流水帳；
- 摘要一律以英文撰寫；
- 翻譯以摘要與原始 SRT 為依據。

現行摘要只看文字，以 VAD-A 組為單位，沒有角色表。

## 決策

1. **摘要語言**：片段、場景、全片三層的摘要與角色簡述一律以英文撰寫，不論影片的來源語言。
   - 角色名保留片中出現的寫法（例如日文漢字），不翻成英文；沒有名字的角色以英文的描述性稱呼表示。
   - 主要文字不是英文的回答視同契約違反，依重試與降級規則處理；檢查容許夾雜角色名與片中原文的短引用。
2. **片段摘要**：每個場景片段附畫面與潤飾後的條目，描述：
   - 在場的人（有名字用名字，否則用描述性稱呼）；
   - 在做什麼、情緒、場所。

   沒有對白的片段也做，只依畫面描述；呼叫成本由 WI-1452 量測。
3. **場景摘要**：以純文字彙整同一場景的片段摘要。
4. **全片摘要**：以純文字彙整場景摘要，產出：
   - 來源語言；
   - **角色表**：每個角色的名字（片中出現者）或描述性稱呼、一句英文簡述；
   - **全片摘要**：依主題或故事段落組織，說明人物、關係、主要事件與情緒變化；不得逐場景、逐時間點條列。
5. **角色名的依據**：名字只採用對白或畫面中出現者，不得杜撰；不確定時用描述性稱呼。
6. **翻譯**：以場景片段為單位，附上：
   - 角色表（含繁體中文譯名，首次翻譯時確定，之後沿用）；
   - 該場景的英文摘要；
   - 前一片段已翻好的譯文作為唯讀語境；
   - 該片段的條目（含行與換人標記）。

   回答須保持條目、行數與換人標記不變。
7. **摘要不阻擋翻譯**：任何一層摘要缺少時，翻譯照常進行，缺少的部分不附。

## 取捨

- 得到：
  - 摘要有畫面依據，可描述行為與情緒；
  - 不論來源語言，摘要的語言一致，便於閱讀與比較不同影片；
  - 角色表讓譯名前後一致；全片摘要可讀。
- 失去：
  - 片段摘要附圖，呼叫成本與潤飾相當；
  - 三層彙整增加流程長度；
  - 角色表依賴模型判斷，可能漏列或誤列；
  - 讀者要讀英文摘要；繁體中文的摘要不在範圍內。

## 後果

- 回答格式的標記：片段與場景摘要為 `SUMMARY:`；全片摘要為 `LANGUAGE:`、`CHARACTERS:`、`SUMMARY:`。各自有 system prompt 參數，可覆寫，但不得刪去標記；預設 prompt 要求以英文撰寫。
- 資料：SEGMENT_SUMMARY、SCENE_SUMMARY、CHARACTER（[06](../06-data-model.md)）。
- 舊的組摘要（GROUP_SUMMARY）不再寫入。
