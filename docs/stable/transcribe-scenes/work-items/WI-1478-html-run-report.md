# WI-1478 每個 run 結束時產生 HTML 報告

本文回答：HTML 報告要達成哪些行為。狀態：已核可（2026-10-15）。相依：WI-1459（翻譯與場景摘要，已完成）；與 WI-1474、1475、1477 無相依，可在獨立 worktree 與分支並行。決策見 [ADR-071](../adr/ADR-071-html-run-report.md)。儲存庫：T。

## 行為與驗收條件

1. **參數**：新增布林參數 `htmlReport`，預設開；README 的參數表與文件測試同步。關閉時不產生報告，其餘行為與輸出與現在完全相同。
2. **時機**：run 以成功或成功但有降級結束時，在字幕檔寫出之後產生報告；失敗、被停止的 run 不產生；續跑的 run 同樣產生。
3. **位置與寫入**：影片旁，檔名「影片檔名.report.html」；已存在同名檔覆蓋；先寫暫存檔再替換，範圍與安全規則沿用 ADR-039（限收件根目錄之內，符號連結解析後仍在其內）；寫出與否記錄在 run 的檔案紀錄中，log 與 RUN SUMMARY 有一行說明。
4. **單檔自足**：只有一個 HTML 檔，資料與樣式內嵌；開啟時不發出任何對外請求；影片以相對路徑引用同目錄的影片檔，不內嵌。
5. **三階段字幕**：播放位置所在的字幕同時顯示三列：ASR（轉錄）、潤飾後、翻譯後；每一列可個別顯示或隱藏；換人標記依 `subtitleDialogueDash` 的設定呈現，與兩份 SRT 一致；一個條目在某階段降級（保留上一階段文字）時仍顯示該階段的實際文字。
6. **播放器**：影片可播放時顯示畫面與聲音，字幕隨播放位置更新；影片不存在或瀏覽器無法播放時退化為時間軸播放，字幕仍隨時間軸更新；完整字幕清單可捲動，點選條目跳到該時間；有播放、暫停與拖曳時間軸的操作。
7. **場景提示**：每個場景有不同的背景色，相鄰場景的顏色有明顯差異且文字可讀；播放位置跨過場景邊界時背景色隨之變換；畫面上持續顯示目前場景的摘要，摘要缺少時顯示「缺少」；全片摘要與角色表可展開查看。
8. **不可信內容**：字幕、摘要、角色名以純文字顯示；內含標記或腳本的文字（例如含 HTML 標籤）不得被執行或改變頁面結構。
9. **失敗隔離**：報告產生或寫出失敗只記錄警告與檔案紀錄，run 的結果與 SRT 不受影響。
10. **舊格式 run**：沒有場景資料的舊 run 不產生報告，不報錯。
11. **重現情境**（真實資料庫與檔案系統）：
    - 預設參數的成功 run：影片旁出現報告檔，內容含三階段文字、每個場景的摘要與場景邊界資訊；
    - `htmlReport` 關閉：沒有報告檔，SRT 不變；
    - 失敗的 run：沒有報告檔；
    - 條目文字含 HTML 標籤與腳本字樣：報告中以純文字呈現；
    - 影片旁目錄不可寫：run 結果不變，警告與檔案紀錄註明未寫出；
    - 報告檔不含任何對外網址的資源引用；
    - 視覺與播放行為（背景色變換、影片同步）在瀏覽器實際開啟檢查，由 tdd-coder 提供檢查步驟與截圖，使用者核對。

## 架構約束

- 不改 Engine；不改 schema；報告是資料庫的唯讀投影，不新增實體。
- 只新增一個參數；不改現有參數的語意。
- 嚴格 TDD；測試不使用 Stub 或 Mock。
- 測試範圍依 tdd-coder 定義的 §1.1，只跑與異動相關的測試，不跑全套。
- 回報時列出測試範圍與結果、jar 路徑與 sha256、提交、一份實際產出的範例報告路徑。
- 部署時需處理：呼叫端（目錄監看、同步工具）必須忽略 `.html`，否則報告會觸發無效 run。
