# WI-1484 片段摘要稱呼自己為「片段」

本文回答：片段層摘要的提示要規定什麼用詞。狀態：已核可（2026-10-18）。相依：無。決策見 [ADR-078](../adr/ADR-078-segment-summary-wording.md)。儲存庫：T。

## 行為與驗收條件

1. **提示規定用詞**：片段層的預設 system prompt 以肯定句規定：摘要的對象稱為 segment（片段）；摘要不使用 scene 一詞；描述片段的結尾時，寫成這個片段的最後發生什麼，不寫場景或影片在此結束。先規定該用的詞，再說明不用的詞。
2. **範圍**：只改片段層。場景層與全片層的提示、請求形狀與取樣參數不變。
3. **覆寫**：仍可覆寫片段層 system prompt；摘要的回答標記不得被刪去（沿用現行規定）。
4. **不改寫回答**：pipeline 不在儲存時替換回答中的用詞。
5. **文件與程式一致**：守住「文件引文與程式中的提示字串完全相同」的測試隨之更新；README 的摘要章節同步。
6. **既有行為不變**：片段摘要的長度上限、英文、涵蓋要求（開頭、中間、結尾）、不描述鏡頭、不分條列。

## 架構約束

- 不改 Engine；不改資料。
- 嚴格 TDD；測試守住提示的規定內容（含肯定用詞、不含 scene 一詞）與覆寫行為。
- 提示改動後的摘要品質（涵蓋度、事實、是否仍寫出 scene）需實機抽樣，由 homelab-deployer 對帶圖片的真實請求量測，不在本項；本項回報提示的完整預設值，供量測使用。
- 以舊提示產生並被續跑沿用的片段摘要保持原樣，不重新產生。
