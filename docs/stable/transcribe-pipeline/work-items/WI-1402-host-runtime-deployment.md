# WI-1402 Engine 主機的轉錄執行環境（選配覆蓋層）

狀態：已核可（2026-10-11），未開始。儲存庫：R。相依：無。本文回答：Docker 與 systemd 的 Engine 部署如何提供 ffmpeg、VAD 工具執行環境與收件目錄。作法同 digest-rss 的瀏覽器覆蓋層（`deploy/browser.md`）。

## 驗收條件

1. Docker：新增選配覆蓋層，使 Engine 容器有 ffmpeg、ffprobe，以及可放置 VAD 工具 jar 與 silero-vad ONNX 模型檔的位置（不需 Python；JRE 已存在），並唯讀掛載收件根目錄、設定 `TRANSCRIBE_INTAKE_ROOT`；不使用覆蓋層時原部署不受影響。
2. systemd：提供對應的 drop-in 與需要的說明；Engine 使用者可讀收件根目錄、不可寫。
3. 容器內以非特權使用者執行這些工具；工作目錄位於可寫的暫存區並在文件說明容量估算（約 115 MB／小時影片加暫時畫面檔）。
4. 提供檢查方式：在容器或主機內確認 ffmpeg 版本、VAD 工具可載入模型並對樣本音訊輸出機率、收件目錄可讀不可寫；失敗時輸出明確原因。
5. 映像與模型檔的版本固定（沿用 ADR-032 以雜湊固定建置輸入的原則）；不含機密。
6. 文件（`deploy/` 下的說明與 README 的部署段）說明需求、設定與驗證步驟。

## 架構約束

- 不改變既有部署預設；單一 Engine 實例。
- 這裡只安裝並驗證執行環境；VAD 工具本身由 WI-1407 交付，此項只需讓它能在該環境執行（工具的安裝位置與命令名稱以 05 的契約為準）。
