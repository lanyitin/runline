# WI-1481 降級或語言不符的片段，以第二個轉錄模型二次轉錄

本文回答：二次轉錄要達成什麼行為、怎樣算完成。狀態：已核可（2026-10-16）。相依：WI-1463、WI-1466、WI-1467。決策見 [ADR-073](../adr/ADR-073-whisper-second-pass.md) 與 [ADR-075](../adr/ADR-075-second-pass-default-on-with-kotoba.md)。儲存庫：T。

## 行為與驗收條件

1. **參數**：
   - 第二個轉錄模型，預設 `Kotoba-Whisper-v2.0`，空值表示關閉；
   - 執行二次轉錄的語言，預設日語；
   - run 語言，空值表示由首次轉錄的文字決定；
   - 書寫系統分類的占比門檻（預設 0.5）與可分類文字的最低數量；
   - 結尾幻覺句清單（預設含 `ご視聴ありがとうございました`）。

   值域在 intake 檢查，錯誤指出參數。
2. **關閉時不變**：模型參數為空時，行為、log、RUN SUMMARY 與沒有此功能時相同。
3. **run 語言**：
   - 語言參數有值就用它；
   - 否則，排除只含語助詞或擬聲的首次轉錄文字，依書寫系統分類（假名＝日語、諺文＝韓語、只有漢字＝中文、其餘＝其他），某一類占比不低於門檻時採該類；
   - 沒有任何一類達到門檻、或可分類文字少於最低數量時，不做二次轉錄，log 說明。
4. **語言範圍**：run 語言不在「執行二次轉錄的語言」清單內時，不做二次轉錄，log 說明原因與 run 語言；其餘行為與關閉時相同。
5. **觸發**：首次轉錄全部完成後、對齊前，下列片段送二次轉錄：
   - 截斷、失敗或低資訊量而降級者；
   - 轉錄文字的書寫系統與 run 語言不符者；只含語助詞或擬聲的文字不算不符。
6. **請求**：語言固定為 run 語言；只送 Engine 資源放行的欄位；只受呼叫逾時保護。
7. **採用**：二次轉錄的文字不是低資訊量、與 run 語言相符、去除結尾幻覺句後仍有文字，才取代該片段的文字；否則維持原結果與降級原因。
8. **採用後**：該片段的對齊（語言為 run 語言）、場景、潤飾、摘要、翻譯與一般片段相同；片段記錄文字來自哪個模型；首次轉錄的文字保留在 EXCHANGE 與片段紀錄；被救回的片段不計入降級與 `transcribeFailed`。
9. **失敗不擴大**：
   - 單次呼叫失敗（逾時、5xx、格式不符）時，該片段維持原結果；這類失敗不計入及早止損，也不使 run 失敗；
   - 設定類失敗（模型不存在、未被資源放行）時，本次 run 其餘片段不再嘗試二次轉錄，log 與 RUN SUMMARY 說明原因，run 照常進行。
10. **可觀測**：結果行與 RUN SUMMARY 列出 run 語言與其來源（參數或文字）、是否執行及略過的原因、觸發片段數（依原因）、採用數、未採用數（依原因）；log 列出片段編號、首次與二次轉錄的語言與採用結果。
11. **續跑**：從轉錄階段（含）以前續跑時，二次轉錄依現行參數重做；從其後階段續跑時沿用結果。
12. **重現（run 43 的樣本，在實機以預設模型驗證）**：
    - run 語言判為日語；
    - 首次轉錄為中文句子的片段（片段 9、49、59、110、115）都被觸發，且二次轉錄的日語文字被採用；
    - 正常對話的對照片段（片段 7、8、10、13、14、48、65、66、67、84）都不被觸發；
    - 二次轉錄的文字沒有結尾幻覺句殘留。

    文字是否比首次轉錄更接近實際，由使用者人工聽測確認（ADR-075 的待確認問題）。
13. **對齊驗證**：二次轉錄的文字經 gateway 對齊成功（或依現行規則改用估計時間並記錄）；若對齊模型不接受該文字，回報而不是繞過。
14. **語言範圍外**：以非日語的測試素材（假服務即可）重現時，結果與關閉時相同，log 有略過的說明。
15. 其餘行為（首次轉錄、生成上限、場景、潤飾、摘要、翻譯、view）不變。

## 架構約束

- 不改 Engine；不新增環境變數或掛載；只新增上述參數。schema 若需新增欄位（文字來源、首次轉錄的文字），先回報再改，且只增不改。
- 觸發、語言與採用判定不呼叫任何 LLM，也不依賴詞典（幻覺句清單是參數）。
- 第二個轉錄模型與對齊模型都經 gateway；不在 Engine 映像加入新的工具。
- 嚴格 TDD；以假服務重現：首次轉錄為中文、降級、低資訊量、二次轉錄成功、二次轉錄仍低資訊量、二次轉錄帶幻覺句、單次呼叫失敗、模型不存在、run 語言不在清單內、無法決定 run 語言。
- 部署時需處理的事（新參數、Lemonade 主機要有已註冊的模型、Engine 資源的放行模型清單）回報時列出。

## 實機驗證

由使用者或 homelab-deployer 執行：以 run 43 的影片，開啟與關閉各一次，比較字幕；人工聽測的結果決定預設是否維持開啟。
