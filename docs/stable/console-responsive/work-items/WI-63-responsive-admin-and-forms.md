# WI-63 管理頁、表單與對話框

本文回答：管理頁、表單與對話框在手機上如何保證可用。狀態：已核可（2026-10-13）。相依：[WI-61](WI-61-responsive-foundation.md)。

## 行為與驗收條件

- 管理頁（trigger 清單與詳情、白名單、使用者與其工作階段、資源與機密、Engine 資訊）中的表格在窄版面於自身容器內水平捲動，第一欄固定；整頁不水平捲動；每列的操作鈕可點。
- 表單頁（上傳、建立 run、trigger 表單、資源的型別化表單、參數表單）在窄版面為單欄，標籤與說明不被截掉，欄位寬度不超出視窗，送出與取消鈕可點。
- 對話框（含確認對話框、版本刪除對話框、使用者工作階段對話框）在窄版面不超出視窗；內容過長時在對話框內垂直捲動，操作鈕保持可見。
- 長參數預設值、多行文字與長名稱在窄版面可閱讀與編輯，不撐破版面。
- 登入頁與錯誤頁（未授權、找不到）在窄版面正常顯示。
- 以上頁面在 360px、390px、768px 下整頁不水平溢位，主要操作可點（以 WI-61 的共用檢查驗證）。
- 既有 Console 測試與 e2e 在寬版面全部通過。

## 架構約束

- 管理頁只保證可用，不逐頁重新設計版面。
- 不修改 Engine 與 API；不改變任何表單的驗證與送出行為。
- 測試不使用 Stub 或 Mock。
