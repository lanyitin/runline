# WI-1412 繁體中文翻譯與 SRT 結果

狀態：已核可（2026-10-11），未開始。儲存庫：T。相依：WI-1411。

## 驗收條件

1. 每個 VAD-A 組把其下核對後字幕與全片摘要（有的話）送 gemma4，要求翻譯為繁體中文；來源語言已是繁體中文時，條目文字原樣保留。
2. 回答須有相同的條目數、順序與時間（ADR-038）；違反者重試，用盡後該組的翻譯欄位使用核對後文字並標記降級。
3. 輸出的繁體中文文字不含簡體字（以抽樣的真實輸出檢查規則定義於專案文件）；不符者視同違反契約處理。
4. 完成後組出兩份 SRT：來源語言（核對後）與繁體中文，條目序號從 1 起、時間格式符合 SRT；「無語音」條目不輸出。兩份 SRT、摘要與來源語言一併寫入結果並更新 run 狀態。
5. run 結尾 log 列出：條目數、各階段降級數、模型呼叫總數與耗時。
6. 以自製的簡易真實對話服務測試，含違反不變式與簡體輸出的案例。

## 架構約束

目標語言固定為繁體中文，不作為參數；輸出格式只有 SRT。
