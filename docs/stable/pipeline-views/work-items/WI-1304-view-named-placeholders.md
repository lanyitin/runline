# WI-1304 View 查詢的具名佔位符

本文回答：view 查詢如何以具名佔位符引用參數，以及上傳與讀取時的行為。狀態：已核可（2026-10-11）。相依：WI-1301（已完成）。儲存庫：runline。

## 背景

見 [ADR-034](../adr/ADR-034-view-parameter-binding.md)。

## 行為與驗收條件

1. 查詢文字以具名佔位符引用已宣告的參數；同一參數出現多次時，每次綁定同一個值。
2. 佔位符只在字串、識別符、註解、錢字號引號之外被辨識；PostgreSQL 的型別轉換記號、字串或註解內的冒號不被當成佔位符。以 PostgreSQL 與 SQLite 的真實語法各驗證。
3. 使用者值只以綁定值傳遞；含引號、分號、佔位符樣式的值，只被當作值。選填參數未提供時綁定為空值。
4. 上傳驗證新增（一次列出全部問題，被拒絕時不留下殘留）：佔位符指向未宣告的參數；已宣告的參數未被引用；查詢使用位置參數標記。
5. 讀取時不再有「參數數量與標記不符」這類錯誤；原本位置綁定的行為與其測試改寫成新行為，不保留舊行為。
6. 唯讀與單一語句的保證不因此減弱：WI-1301 的唯讀、多語句與改回可寫測試全部維持通過。
7. 08-api 與 `core/README.md` 的宣告說明改寫為最新規則，不留位置綁定的描述。

## 架構約束

- 不拼接使用者值進查詢文字。
- 沿用既有的詞法分析器擴充，不另建第二套。
- 測試不使用 Stub 或 Mock；資料庫用真實 PostgreSQL 與真實 SQLite。
