# ADR-066 降級完成的 run 也可以續跑

本文回答：哪些狀態的 run 可以當續跑的來源，以及續跑時如何傳參數。狀態：已核可（2026-10-15）。修改 [ADR-063](ADR-063-resume-run-from-stage.md) 決策 6 中「來源 run 為失敗或中斷」的條件與 [WI-1467](../work-items/WI-1467-resume-run-from-stage.md) 條件 2 的對應部分；其餘不變。

## 背景

- 實機 run 19 以 success-degraded 結束：535 條中有 74 條因翻譯降級退回日文，另有 104 條在判定為成功的片段中沒有翻譯。使用者要對它從翻譯重做。
- ADR-063 只允許失敗或中斷的 run 當來源，所以續跑在 `intake` 被拒絕（「only a failed or interrupted run can be resumed」）。
- 降級完成正是重做單一階段最有價值的情況：資料齊全，只是某個階段的部分單位品質不好；整個 run 重做要約 1.5 小時以上，只重做該階段約 12 分鐘。
- 續跑時由呼叫端整份重送參數會出問題：Engine 把沒送的參數補成預設值並記入該 run，包括各階段的 system prompt 全文。照來源 run 的值整份重送，會用舊版的預設提示詞蓋掉新版 jar 的預設。

## 決策

1. **來源 run 的狀態**：可續跑的來源為失敗、中斷、以及降級完成（success-degraded）。完全成功（沒有任何降級）的 run 仍不可當來源，避免誤把已完成的結果重做；要重做時送一般 run。其餘驗證（資料完整、影片仍在、尚未被保留規則清除、同一支影片）不變。
2. **降級完成的來源，起點之前的階段中降級的單位照常取用**：起點之前的階段不重算，即使其中有降級的單位（例如轉錄失敗的片段）；要重做那些單位，把起點設在該階段。起點階段按 ADR-063 的規則延續：已完整完成的單位沿用，降級（退回原文、沒有文字）的單位視為未完成，重做。
3. **「完整完成」的定義**：單位只在成功（含重試後成功、或部分條目採用的條目）時才算完成並沿用；整個單位降級退回上一階段文字者，視為未完成。部分條目採用的片段，採用的條目沿用，其餘條目重做。此定義同時適用於失敗與中斷的來源。
4. **參數傳遞原則**：續跑只需送要變更的參數；沒送的參數由 Engine 補上目前 jar 的預設值，不從來源 run 繼承。使用者若要延續來源 run 的某個非預設值，須明確送出該值。起點之前階段的專屬參數仍固定取自來源 run（ADR-063 決策 5），所以不會因此與已沿用的資料不一致。README 以此為操作原則，並警告不要整份重送來源 run 的參數，特別是各階段的 system prompt。

## 取捨

- 得到：降級完成的 run 可以只重做品質不好的階段；新版 jar 的預設值（含提示詞）不會被舊值蓋掉。
- 失去：
  - 降級完成的 run 可被續跑，多一個重做的入口，需要在 README 與 view 說明；來源 run 本身仍不被改動。
  - 續跑不再繼承來源 run 的非預設參數，呼叫端若忘了重送自訂值，會用到預設值；以 log 的參數摘要提示（見 WI-1470）。
- 不採用：允許任何已結束的 run 當來源。完全成功的 run 重做通常是誤操作，保留拒絕；若日後需要再開。
