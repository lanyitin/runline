## 全域架構約束

- 只跟隨系統設定，不新增開關、不儲存偏好（[ADR-70](../adr/ADR-70-console-dark-mode.md)）。
- 深色值放在 token 層；元件不自訂顏色；淺色的值與外觀不變。
- 只用同源的 `/api/v1`，不改變任何 API 契約，不修改 Engine。
- 文字與背景對比至少 4.5:1，大字與元件邊界至少 3:1。
- 新增的文案（若有）走多語系機制，所有支援的語言都有。
- 既有 Console 測試與 e2e 必須全部通過；不得以放寬斷言達成。
- 測試不使用 Stub 或 Mock；遵循 TDD；專案沒有 CI，驗證皆可在本機完成。
