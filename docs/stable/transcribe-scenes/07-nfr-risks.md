# 7 非功能性考量與風險

狀態：已核可（2026-10-14）。本文回答：新流程的處理時間是否能落在目標內、超出時怎麼調、失敗時怎麼表現，以及主要風險。

## 處理時間目標

一小時影片 3 小時內完成。這是軟性目標，用來決定預設值，不設成逾時；準確度優先。

## 容量估算（一小時影片；單次耗時待 WI-1451、WI-1452 量測）

| 階段 | 次數 | 單次耗時（假設） | 小計 |
|---|---|---|---|
| 擷取、降噪、VAD | 1 | 實測約 13 分（run 8） | 約 13 分 |
| 轉錄 | 約 120 | 5 至 15 秒 | 10 至 30 分 |
| 對齊（CPU） | 約 120 | 待量測 | 待量測 |
| 場景偵測 | 1 | 與影片長度成正比，待量測 | 待量測 |
| 潤飾（附圖，thinking 關） | 約 300 | 10 至 20 秒 | 50 至 100 分 |
| 片段摘要（附圖） | 約 300 | 10 至 20 秒 | 50 至 100 分 |
| 場景與全片摘要 | 數十 | 數秒 | 數分 |
| 翻譯 | 約 300 | 10 至 15 秒 | 50 至 75 分 |

估算總計約 3 至 5 小時。附圖的單次耗時是最大的不確定，由 WI-1452 量測。

**超出目標時的旋鈕**（依序使用，都不降低文字層的契約）：

1. `framesPerSegment`：每個片段的圖片數上限（每秒一張，等距取樣到上限）。
2. `segmentTargetSeconds`：場景片段長度（較長的片段，呼叫次數較少，單次較慢）。
3. 片段摘要與潤飾共用同一次請求（[03](03-options.md) 選項 F2）。

## 失敗模式與降級

| 情況 | 表現 |
|---|---|
| 某個長片段轉錄失敗（重試用盡） | 該片段沒有字幕，計入降級；run 繼續 |
| 對齊失敗 | 該片段的文字依字數比例分配到片段時間內，切成不超過長度原則的條目，標為估計時間，計入降級 |
| 場景偵測失敗 | 整部影片視為一個場景，再依長度切成片段，計入降級 |
| 潤飾、翻譯的某片段失敗 | 保留上一階段文字（翻譯則保留來源語言），該片段沒有換人標記，計入降級 |
| 摘要失敗 | 對應層缺摘要，上一層照常以現有內容彙整 |
| 同一階段因同一原因連續失敗（及早止損） | 該 run 在達到門檻時停止並失敗，分類指出階段與原因，不再耗費時間（[ADR-055](adr/ADR-055-thinking-policy-and-early-stop.md)） |
| 對齊工具或模型檔缺漏 | run 以明確的設定類失敗結束 |

## 可觀測性

- 每個階段的 log 結果行加上：片段數、場景數、場景片段數、對齊失敗數、換人標記數、推理 token 總數。
- EXCHANGE 記錄推理內容與上游 HTTP 狀態（[06](06-data-model.md)）。
- RUN SUMMARY 記錄各階段耗時，便於對照 3 小時目標。

## 安全

- 畫面與音訊只在記憶體與工作目錄，不進資料庫與 log（沿用）。
- 對齊工具是本機子行程，不開網路連線；模型檔隨映像固定雜湊。
- 新增的 Python 環境擴大了映像的供應鏈範圍：版本固定、建置時驗證雜湊，執行時不安裝任何套件。

## 風險

| 風險 | 影響 | 緩解 |
|---|---|---|
| 對齊在雜音、喘息、多人重疊時不準 | 字幕時間偏移 | WI-1451 以真實素材量測；失敗時有估計時間的退路 |
| 30 秒片段中的非語音段引發 ASR 幻覺 | 字幕出現不存在的句子 | 整段無語音的片段不送；WI-1452 比較幻覺率；必要時加入語言與字數過濾 |
| 場景偵測對運鏡、光線誤切或漏切 | 片段邊界不自然，影響換人與摘要 | 門檻與最短場景長度可調；片段內仍附前一片段的語境 |
| LLM 誤判換人 | 讀者被錯誤的破折號誤導 | 破折號可關閉；WI-1452 抽樣驗證；換人資料可查，便於比對 |
| 附圖請求耗時超出估計 | 超過 3 小時目標 | 上方的旋鈕 |
| 映像變大 | 建置與拉取時間增加 | 量測後寫入 04；只有 `transcribe` 系列映像受影響 |
| 長期獨佔 Lemonade | digest-rss 等候 | 沿用現行的排程建議（stable runbook 第 14 節） |
