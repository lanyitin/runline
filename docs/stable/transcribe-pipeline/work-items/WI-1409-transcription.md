# WI-1409 轉錄模型轉錄（端點依 labels 選擇見 [ADR-042](../adr/ADR-042-asr-by-model-labels.md)）

狀態：已核可（2026-10-11），未開始。儲存庫：T。相依：WI-1404、WI-1405、WI-1408。

## 驗收條件

1. 每個 VAD-B 段依其起訖從 WAV 切出音訊（位元組），經 LLM 資源的音訊轉錄端點送出；模型名稱、語言提示與請求參數來自 pipeline 參數。
2. 逐段循序進行；回傳文字寫入紀錄的轉錄欄位，條目的時間不變。
3. 空白或僅標點的結果記為「無語音」，條目保留且文字為空，後續階段依此處理；計數寫入 log。
4. 單段失敗依參數重試；用盡後整個 run 失敗，訊息含條目序號與時間，不含音訊。
5. 回報的實際模型 id 寫入紀錄；與請求不符時沿用 digest-rss 的模型身分規則（ADR-028）處理。
6. 進度：每完成固定數量的段落寫入 log（已完成／總數）；取消時在當前呼叫結束後停止，已完成部分保留。
7. 使用真實 Engine 資源路徑與自製的簡易真實轉錄服務（遵守 OpenAI 相容音訊轉錄協定）測試；對真實 Lemonade 的驗證歸 WI-1413。

## 架構約束

不保存音訊；不在 pipeline 內持有位址或機密；並行 1。
