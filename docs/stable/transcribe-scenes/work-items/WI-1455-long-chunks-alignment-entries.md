# WI-1455 長片段切分、轉錄、對齊與組成條目

本文回答：pipeline 如何從 VAD 機率得到長片段、轉錄並對齊，再組成字幕條目。狀態：已核可（2026-10-14）。相依：WI-1452、WI-1453、WI-1454。決策見 [ADR-051](../adr/ADR-051-long-chunks-and-forced-alignment.md)。儲存庫：T。

## 行為與驗收條件

1. **長片段**：
   - 片段連續覆蓋整條時間軸，不重疊、沒有空隙；
   - 每段接近 `chunkTargetSeconds`、不超過 `chunkMaxSeconds`，切點在目標長度附近語音機率最低處；
   - 整段無語音者標為無語音，不送轉錄。
2. **轉錄**：有語音的片段取原始音訊（不是降噪後的音訊）送轉錄模型；重試、逾時、止損沿用 WI-1453。
3. **對齊**：每個轉錄成功的片段呼叫對齊工具。對齊失敗時，文字依字數比例分配到片段時間內並標為估計時間，計入降級。
4. **組成條目**：
   - 優先在句末標點與停頓（超過 `subtitlePauseSeconds`）處斷開；
   - 每條不超過 `subtitleMaxSeconds` 與每行字數上限，至多兩行；
   - 短於 `subtitleMinSeconds` 者在不重疊的前提下延長；
   - 組成後條目的數量與時間固定。
5. **不變式的檢查**：對任何輸入，條目不重疊、依時間排序、長度不超過上限；有測試涵蓋邊界（片段首尾、極短語音、長獨白、對齊失敗）。
6. **移除**：VAD-A／B 分段、補掃、輸出時合併及其參數；舊 run 的資料照常可查。
7. **紀錄**：CHUNK、ALIGNED_TOKEN、ENTRY、ENTRY_LINE（轉錄階段）依 [06](../06-data-model.md) 寫入；每個片段一個交易。log 的結果行列出片段數、無語音數、對齊失敗數、條目數。
8. 在此項完成時，後續階段（潤飾、摘要、翻譯）暫時以「整部影片一個場景、依長度切成片段」運作，讓 run 可以完整跑完；WI-1456 起替換。

## 架構約束

- 降噪只供 VAD；轉錄與對齊取原始音訊。
- 條目在組成後數量與時間固定，後續階段只能改文字與換人資料。
- 結構只增不改。
- 嚴格 TDD；測試不使用 Stub 或 Mock（對齊工具在測試中以真實工具或自製的簡易真實實作代替）。
