# #29：pipeline view 以大型 popup 呈現

本項回答：Console 如何把 pipeline view 放進約 95% viewport 的 popup。狀態：已核可（2026-10-19），已完成（2026-10-19）。Issue：#29。相依：無（WI-1302 已完成）。儲存庫：runline。入口：[README](../README.md)。

## 目標

使用者在 pipeline 詳情頁選一個 view，看到一個佔視窗約 95% 的 popup，其中有該 view 的完整操作；關閉後回到詳情頁。

## 驗收條件

1. 詳情頁的「資料」區列出該版本的 view 清單，內容與可否執行的狀態同 WI-1302；選一個 view 前不顯示表格。沒有宣告 view 的 pipeline 仍不顯示此區。
2. 選一個 view 開啟 popup：寬度與高度各約佔視窗 95%，置中；參數輸入、表格、分頁與鑽取都在 popup 內，功能與 WI-1302 的行為一致。內容過多時在 popup 內捲動，背景頁不捲動。
3. popup 的開關由網址決定：網址帶有 view 即開，否則即關。view、參數值與頁碼仍在網址；重新整理、貼連結開啟、瀏覽器上一頁／下一頁都回到相同狀態（直接開啟帶 view 的網址，popup 開啟並顯示該表）。
4. 關閉方式：關閉鈕與 Esc。關閉後網址移除 view，焦點回到開啟它的清單項目。
5. 鑽取：點選宣告了鑽取的欄位，popup 不關閉，內容換成目標 view 並帶入參數；「返回」回到上一個 view，保留原參數與頁碼。
6. 窄版面（768px 以下，ADR-048）popup 為全螢幕；整頁不水平溢位；操作鈕保持可見且可點區域符合 ADR-048 第 8 點；表格維持自身容器內水平捲動、第一欄固定。
7. 可及性：popup 有名稱（view 標題）、開啟時焦點進入、Tab 不離開、關閉時焦點返回；沿用 Console 既有對話框的行為。
8. 既有規則不變：儲存格值當純文字、錯誤說明與重試、zh-TW 與 en 兩種語言、開發人員與管理員的可見範圍（WI-1302 第 3、5、6、7 點）。新增的固定介面文字走多語系。
9. 既有 Console 測試與 e2e 通過；新增的 e2e 覆蓋：開啟、直接開啟網址、重新整理、鑽取後返回、Esc 關閉、手機尺寸全螢幕。

## 架構約束

- 只改 Console 的呈現；不改 Engine、API、view 宣告或其契約。
- 不新增路由、不新增頂層導覽；popup 狀態只來自網址，不另存一份。
- 只用同源相對路徑，不引入第三方腳本、字型或套件。
- 寬版面下詳情頁的其他區塊與行為不變。
- 實作方式（元件與測試設計）由 tdd-coder 決定，須遵守專案的 TDD 與既有 Console 慣例。
