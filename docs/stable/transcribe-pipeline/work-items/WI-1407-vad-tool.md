# WI-1407 VAD 命令列工具（語音機率）

狀態：已核可（2026-10-11），未開始。儲存庫：T（獨立建置單元，產出一個可用 JRE 執行的 jar；與 pipeline jar 分開，不進 pipeline）。相依：WI-1403。契約見 [05](../05-ipc.md)，選型見 [03](../03-options.md) 3.3。

## 驗收條件

1. 輸入 16 kHz 單聲道 WAV 與模型檔位置，標準輸出為整個檔案每個固定長度視窗的語音機率，並說明視窗長度與取樣率；診斷走標準錯誤；成功結束碼 0，失敗非 0 並說明原因。
2. 同一輸入與模型的輸出逐值相同（可重現）；一次呼叫處理整個檔案。
3. 對含明確停頓的真實語音樣本：說話處機率高、停頓處機率低；對照官方 silero-vad Python 實作對同一樣本產出的機率，差異在容許誤差內（容許值於此項依實測定稿並寫入專案文件；對照基準檔隨專案保存）。
4. 檔案不是 16 kHz 單聲道 WAV 時失敗並說明；無語音的音訊輸出全低機率且結束碼 0。
5. 模型檔缺少或雜湊與固定值不符時失敗並指出原因，不連網下載。
6. 模型版本與雜湊固定並記錄於專案文件；可在兩個行程同時執行而互不影響（各自的 JVM）。
7. 以真實 ONNX Runtime 與真實音訊樣本測試，不使用替身；測試樣本使用可再散布的語音（TTS 或公開授權）。

## 架構約束

不連網；僅 CPU；工具不含判定參數（門檻、最小靜音等屬 WI-1408 的 pipeline 側）；pipeline 不依賴工具內部實作，只依契約。
