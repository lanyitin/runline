# WI-1404 可行性關卡：Lemonade 的音訊轉錄與圖片輸入

狀態：已核可（2026-10-11），未開始。儲存庫：T。相依：WI-1403。本文回答：全案依賴的兩個外部能力是否成立。

## 驗收條件

1. 經 Engine 的 `openai-compatible` 資源（不繞過資源），把一段 25 秒、單聲道 16 kHz 的音訊以位元組送到音訊轉錄端點，轉錄模型回傳文字（chat 型轉錄模型改走對話端點的音訊輸入，見 [ADR-042](../adr/ADR-042-asr-by-model-labels.md)）；記錄所需的端點啟用與請求大小設定。
2. 經同一資源，把含 6 張縮圖與文字的請求送到對話端點，gemma4 回傳與圖片相關的文字；記錄縮圖邊長與請求大小上限的可行範圍。
3. 以文字請求要求 gemma4 輸出與輸入相同條目數與時間的 SRT，量測遵守率（至少 20 組樣本），結果與觀察寫入報告。
4. 量測單次呼叫耗時與模型切換耗時（轉錄模型與 gemma4 之間），供 [07](../07-nfr-risks.md) 的容量估算修正。
5. 產出一份報告（放在 `docs/draft/transcribe-pipeline/` 下的檔案）：通過、條件通過或失敗，及所需的資源與端點設定。任何一項失敗時停下回報，由架構決定，不自行繞過。

## 架構約束

使用者在有 Lemonade 的環境執行真實量測；沒有真實服務時，報告標明「未驗證」，不以 stub 代替結論。
