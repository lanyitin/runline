# ADR-082 欄位固定的層被截斷且沒有完整欄位時，保存殘文字

本文回答：場景層與中間彙整的回答被截斷、一個完整欄位也沒有時，要降級還是保存。狀態：已核可（2026-10-18）。解答 [ADR-080](ADR-080-summary-degradation-conditions.md) 待確認問題 1。

## 背景

- ADR-080 決策 7：欄位缺漏不降級；[ADR-079](ADR-079-truncated-summary-is-kept-and-flagged.md)：被截斷的摘要保存並在下一層的輸入中標明。
- 使用者的原則：一次 run 耗時數小時，品質優先但盡量保存資料，事後能找出問題單位即可。

## 決策

1. 回答被截斷、且一個完整欄位也沒有時，保存已有的內容，不降級。
2. 該摘要依 ADR-079 記錄為被截斷，下一層的輸入標明它不完整。
3. 與 [WI-1486](../work-items/WI-1486-scene-summary-field-block-only.md) 第 6 條一致，WI-1486 的範圍與驗收條件不變。

## 取捨

- 得到：不新增降級規則；保存的資料可事後查驗；下一層得知內容不完整。
- 失去：殘文字可能是未寫完的自言自語，會進入下一層的輸入；只靠被截斷標示讓下一層斟酌。

## 後果

- 若實作後的 run 資料顯示殘文字常污染下一層，再以新 ADR 重新討論降級。
