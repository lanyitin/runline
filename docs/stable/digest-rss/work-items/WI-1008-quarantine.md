# WI-1008 隔離清單

目標：一再無法判定的文章暫時不再消耗成本。行為參考：來源的 `unjudged-ledger.mjs`。工作儲存庫：`runline-digest-rss`。

## 驗收條件

1. 文章在一次 run 中未得出判定即累計一次；連續 3 次（可設定）後隔離 7 天（可設定）。
2. 隔離期間該文章不進入候選，RUN_POST 記錄「隔離」為未處理原因；它在 FreshRSS 仍為未讀，絕不被標已讀。
3. 得出判定後忘記該文章；隔離到期後恢復嘗試。
4. 狀態存於資料庫的 QUARANTINE，跨 run 保留；無紀錄視為無隔離。
5. 紀錄寫入失敗不使 run 失敗。

## 架構約束

- 無檔案寫入；沿用 WI-1004 的紀錄基礎。
