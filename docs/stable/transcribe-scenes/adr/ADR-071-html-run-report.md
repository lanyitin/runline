# ADR-071 每個 run 結束時產生 HTML 報告，以播放器形式對照三階段字幕與場景

本文回答：run 結束後如何讓使用者在瀏覽器裡核對 ASR、潤飾、翻譯三階段的字幕與場景摘要，以及檔案放在哪裡、由什麼參數控制。狀態：已核可（2026-10-15）。修改 [ADR-039（transcribe-pipeline）](../../transcribe-pipeline/adr/ADR-039-subtitle-files-beside-video.md) 的檔案範圍：影片旁除了兩個字幕檔，再多一個報告檔。

## 背景

- 使用者在成品核對時要判斷日文品質、時間精度、換人標記與場景切分；現在要靠 SRT 與資料庫 view 逐項比對，三階段的文字差異與場景邊界看不出來。
- 資料已在 `transcribe.db`：條目與各階段文字（ENTRY、ENTRY_LINE）、場景與場景片段、場景摘要、全片摘要與角色表（見 [06](../06-data-model.md)）。缺的只是呈現。
- 影片約 1.5 GB，不能內嵌進報告。

## 決策

1. **參數**：新增一個布林參數控制是否產生報告，預設為開（名稱 `htmlReport`）。關閉時 run 的其他行為與輸出完全不變。
2. **時機與範圍**：run 的最後階段（`export` 之後）產生；run 以成功或成功但有降級結束時產生，失敗與被停止的 run 不產生。續跑的 run 同樣產生。
3. **位置**：影片旁，檔名為「影片檔名.report.html」；已存在的同名檔覆蓋。寫入規則沿用 ADR-039：範圍限收件根目錄之內、先寫暫存檔再替換、寫出與否記錄在 run 的檔案紀錄中。
4. **單檔自足**：報告是單一 HTML 檔，資料與樣式內嵌，不載入任何外部資源（無網路字型、無 CDN）。影片不內嵌，以相對路徑引用同目錄的影片檔。
5. **播放器形式**：
   - 頁面主體是影片播放器；影片檔存在且瀏覽器能播放時顯示畫面與聲音，否則退化為只有時間軸的播放（以時間軸捲動字幕，不依賴影片）。
   - 播放位置所在的字幕以三列同時顯示：ASR（轉錄）、潤飾後、翻譯後；每一列可個別顯示或隱藏。換人標記照 `subtitleDialogueDash` 的呈現方式。
   - 完整的字幕清單可捲動，點選任一條目跳到該時間。
6. **場景提示**：每個場景用不同的背景色，播放位置進入下一個場景時背景色變換；顏色在相鄰場景之間必須有明顯差異，且文字對比符合可讀性。畫面上持續顯示目前場景的摘要（場景摘要缺少時註明缺少）；全片摘要與角色表另有一處可展開查看。
7. **內容的信任邊界**：字幕、摘要、角色名都是模型輸出，一律視為不可信文字，以純文字顯示，不得被當成標記或腳本執行。
8. **失敗隔離**：報告產生或寫出失敗只記錄警告與檔案紀錄，不改變 run 的結果。
9. **不改資料**：報告是資料庫的唯讀投影，不新增實體、不改 schema。

## 取捨

- 得到：一個檔就能核對三階段文字與場景邊界；不需要 Console 或資料庫工具；可以隨影片一起保存。
- 失去：影片旁多一個檔，外部監看新檔的系統必須忽略 `.html`（與 ADR-039 對 `.srt` 的要求相同）；報告的影片播放受瀏覽器對編碼的支援限制；報告檔的大小隨條目數增加（一小時影片估計為數百 KB 到數 MB）。
- 不採用：
  - 只在 Console 顯示（Console 需要 Engine 在線，也無法隨檔案保存）；
  - 內嵌影片（檔案過大）；
  - 預設關閉（使用者要求預設開）。

## 後果

- 新工作項：[WI-1478](../work-items/WI-1478-html-run-report.md)。

## 待確認問題

- 失敗或被停止的 run 是否也要產生（含部分資料）。本 ADR 預設不產生。
- 降級的條目是否在報告中標記；本 ADR 不含，需要的話另開工作項。
