# WI-1454 對齊工具進入映像與主機部署

本文回答：對齊工具與模型檔如何隨 Engine 部署、如何驗證可用。狀態：已核可（2026-10-14）。相依：WI-1451。決策見 [ADR-051](../adr/ADR-051-long-chunks-and-forced-alignment.md)，部署見 [04](../04-deployment.md)。儲存庫：R（映像、部署腳本與文件），T（工具本身，若 WI-1451 留在 T）。

## 行為與驗收條件

1. `transcribe` 與 `browser-transcribe` 兩個映像階段含有對齊工具、固定版本的 Python 環境與模型檔；其他映像階段不變。
2. 模型檔與相依以雜湊固定，`check-pins` 涵蓋它們；執行時不連網下載。
3. 任意 uid 執行時工具可用（沿用 ADR-041 的檢查方式）。
4. `runline-entrypoint` 的啟動報告列出工具版本與模型檔雜湊。只報告、不攔阻。
5. 部署的自動檢查實際對一段短音訊執行對齊並成功；工具或模型檔缺漏時，檢查以明確訊息失敗。
6. systemd 主機部署的前置條件與環境變數寫入 `deploy/transcribe.md`。
7. 記錄映像大小的變化。

## 架構約束

- 工具是 pipeline 啟動的本機子行程，不開網路連線。
- 不改 Engine 的程式；Engine 不依賴對齊工具，工具缺漏只影響使用它的 run。
- 嚴格 TDD；部署檢查以真實映像執行。
