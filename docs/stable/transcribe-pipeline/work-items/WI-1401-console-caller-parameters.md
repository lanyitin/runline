# WI-1401 Console 的呼叫端提供參數設定

狀態：已核可（2026-10-11），未開始（可延後）。儲存庫：R。相依：WI-1400。本文回答：Console 要讓管理員能設定與檢視呼叫端提供的參數。

## 驗收條件

1. 建立與編輯 webhook trigger 的表單，可從綁定版本的參數中勾選哪些由呼叫端提供；已固定的參數不能同時勾選。
2. 勾選後，必填且無預設的參數若既未固定也未勾選，表單顯示 API 回報的錯誤並指出參數名稱。
3. trigger 清單與詳情顯示呼叫端提供的參數名稱；cron trigger 不顯示此欄。
4. Console 單元測試、契約測試與 e2e 涵蓋上述行為；既有 `dev/verify-console-security.sh` 通過。

## 架構約束

沿用 Console 既有的語言、設計 token 與認證方式；不新增前端依賴。
