# WI-1408 VAD-A 與 VAD-B 分段

狀態：已核可（2026-10-11），未開始。儲存庫：T。相依：WI-1405、WI-1406、WI-1407。規則見 [ADR-038](../adr/ADR-038-segment-model-and-stage-invariants.md) 第 0 至 2 點。

## 驗收條件

0. 語音機率由 VAD 工具一次取得（WI-1407），門檻、最小靜音、最小語音長度的判定在 pipeline 內實作，規則對應官方 silero-vad 的語音區間偵測；對 WI-1407 保存的基準音訊，判定結果與官方 Python 實作產出的區間一致（邊界誤差容許值於此項定稿，不超過一個視窗長度）。VAD-B 的再偵測使用同一份機率，只套用於所屬 VAD-A 的區間。
1. VAD-A：每段不超過 `maxSegmentSeconds`；過長的語音區間在搜尋範圍內於短時間能量最低點切開，兩側皆不短於最小片段長度；重複直到都符合。以含明確低能量點的合成音訊驗證切點位置。
2. 沒有低能量點可選（例如整段連續高能量）時仍然完成切分，不無窮迴圈，並在 log 記錄。
3. VAD-B：只有長度超過 `refineThresholdSeconds` 的 VAD-A 才以較短最小靜音重新偵測；其餘原樣成為一個 VAD-B；再偵測無法切開時維持原樣。
4. 每個 VAD-B 屬於且僅屬於一個 VAD-A；時間落在所屬 VAD-A 內；同一 run 內 VAD-B 不重疊且依時間排序。
5. 全部參數（兩組 VAD 參數、25／6 秒門檻、搜尋範圍、最小片段長度）可由 pipeline 參數控制；不合理組合（B 的最小靜音不短於 A 等）在初始階段被拒絕並指出參數。
6. 結果寫入紀錄：A 與 B 的起訖、從屬、是否沿用；階段計數寫入 log。
7. 整段沒有語音時，run 以明確原因失敗（沒有可轉錄的語音）。
8. 以真實 VAD 工具與真實 WAV 測試。

## 架構約束

判定、能量計算與切點選擇在 pipeline 內以 JDK 完成；不改變 VAD 工具契約。
