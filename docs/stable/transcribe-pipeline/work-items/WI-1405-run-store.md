# WI-1405 SQLite 紀錄

狀態：已核可（2026-10-11），未開始。儲存庫：T。相依：WI-1403。資料模型見 [06](../06-data-model.md)。

## 驗收條件

1. 首次使用時建立結構；結構有版本，版本較新或不認得時 run 失敗並說明，不覆蓋資料。
2. 能記錄 06 列出的全部實體：run、階段、VAD-A、VAD-B、各階段條目文字（含畫面時間點與觀察）、模型對話、結果；沒有任何欄位可存放音訊或圖片。
3. 每個階段結果在單一交易內寫入；中途失敗不留下半個階段的資料。
4. 可依 run 取回 SRT（來源語言與繁體中文）、摘要、各階段計數與降級數，以及某條目各階段的文字。
5. 每個 run 開始時依 `retentionDays` 清除過期的 run 及其下資料；單次清除有批次上限，不長時間佔用資料庫。
6. 資料庫不可用時 run 在初始階段失敗並指出原因；錯誤不洩漏連線機密。
7. 以真實 SQLite 檔（含 Engine 的 `sqlite` 種類路徑）測試，包括同時兩個 run 寫入。

## 架構約束

只增不改的結構演進；沿用 digest-rss 的資料保存原則（ADR-024）；寫入透過 `jdbc-pool` 資源。
