# WI-1456 場景偵測與場景片段

本文回答：pipeline 如何切出場景與場景片段，並把條目歸屬到片段。狀態：已核可（2026-10-14）。相依：WI-1455。決策見 [ADR-052](../adr/ADR-052-scenes-as-llm-units.md)。儲存庫：T。

## 行為與驗收條件

1. **場景偵測**：以 ffmpeg 的場景分數偵測畫面切換：
   - 超過 `sceneThreshold` 處為邊界；
   - 短於 `sceneMinSeconds` 的場景併入前一個；
   - 場景連續覆蓋整部影片。
2. **退路**：影片沒有畫面時，整部影片為一個場景，不計降級；偵測失敗時，同樣整部影片為一個場景，計入降級並記錄原因。
3. **場景片段**：長於 `segmentTargetSeconds` 的場景，切成接近該長度的片段：
   - 切點在條目之間的空隙，條目不跨片段；
   - 沒有空隙時選在最近的條目邊界。
4. **歸屬**：每個條目依起點歸屬到唯一一個片段；沒有條目的片段照樣存在（供摘要）。
5. **紀錄**：SCENE、SCENE_SEGMENT 依 [06](../06-data-model.md) 寫入；log 的結果行列出場景數、片段數、片段長度的中位數與最大值、偵測耗時。
6. 後續階段改以本項的場景片段為單位，取代 WI-1455 的暫時切法。

## 架構約束

- 只用既有的 ffmpeg，不新增工具。
- 不改條目的數量與時間。
- 嚴格 TDD；場景偵測以真實 ffmpeg 與合成影片測試。
