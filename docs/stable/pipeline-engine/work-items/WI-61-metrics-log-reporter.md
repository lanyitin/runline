# WI-61 指標不定期寫入 log，停止時不留背景工作

本文回答：Engine 的指標輸出要改成什麼樣子，以及如何驗收。狀態：已核可（2026-10-08）。相依：無。決策見[07](../07-nfr-risks.md)「可觀測性」。

## 背景

每個 Engine 應用程式都會啟動一個每秒把所有指標寫進 log 的輸出器，Engine 停止時沒有停止它。在測試的 JVM 中，它會累積到約 300 個，每秒約 2,400 行 log（[WI-57](WI-57-test-environment-robustness.md)「實作結果」）。

## 行為與驗收條件

- Engine 不再定期把指標寫進 log。Engine 執行數秒、期間沒有任何事件時，log 中沒有指標行。
- 07 與 08-api 已記載的 metric 名稱、標籤與 OTLP 匯出不變；既有 metric 測試全部通過。
- Engine 停止後，它啟動的指標、匯出與排程相關背景執行緒都已結束。驗證方式：同一個 JVM 內連續啟動並停止 Engine 至少 20 次，前後的存活執行緒集合中，沒有屬於這些工作的執行緒累積。

## 架構約束

- 不改變任何 API、metric 名稱、標籤或 trace 結構。
- 不新增任何設定開關來恢復定期寫 log。
- 測試不使用 Stub 或 Mock。
