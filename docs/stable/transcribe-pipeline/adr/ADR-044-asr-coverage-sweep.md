# ADR-044 VAD 空隙以 ASR 補掃

本文回答：VAD 沒有偵測到、但實際有人聲的區段，如何仍被轉錄。狀態：已核可（2026-10-13）。補充 [ADR-038](ADR-038-segment-model-and-stage-invariants.md) 決策 0 至 3（字幕條目只來自 VAD-B 段）；不取代其不變式。

## 背景

arr 的實驗（NTRH-002-C.mp4，234 秒）顯示：

- 以 silero 規則偵測，覆蓋率只有 13.8%（門檻 0.5）至 17.9%（門檻 0.3）；大空隙長達 20 至 41 秒。
- 空隙內的 VAD 機率最大值僅 0.2 至 0.3、平均約 0.003，但這些空隙的音量不小（部分窗口 RMS 約 -25 dB，與有語音的窗口相當）。
- 對空隙每 8 秒一段直接送 Qwen3-ASR，多段得到完整的日語句子（例如「ちょっと心の準備ができてないよ」「おやじ、帰ってきたよ」）。ASR 每段 57 至 210 毫秒。
- 音量正規化（loudnorm、dynaudnorm）與頻帶濾波對 VAD 覆蓋率沒有實質改善（門檻 0.5 時涵蓋 10.2% 至 12.7%，低於原始）。
- 門檻 0.3 新增的零碎區段，ASR 多回中文單字（嗯、啊、哦、就、哭）：是雜音造成的幻覺，不是語音。

結論：VAD 對這類音訊（人聲混有環境聲或背景聲）召回不足，且音訊前處理無法補救；ASR 本身能從同樣的音訊辨識出語音，成本低。

## 決策

1. VAD-B 分段之後，找出相鄰條目之間超過 `sweepMinGapSeconds` 的空隙（含影片開頭與結尾）。
2. 空隙以固定長度 `sweepWindowSeconds` 切成連續窗口（最後一個窗口可較短，但不短於最小片段長度），逐窗口送給同一個轉錄模型與同一條端點。
3. 回答為 `language None` 或空，視為沒有語音，丟棄。
4. 回答經幻覺過濾：語言與整部影片的主要語言（以 VAD 段的轉錄結果多數決）不同，且文字長度小於 `sweepMinChars` 的窗口，丟棄並計數。主要語言一致、或文字長度達標者保留。被過濾的窗口記入 log 與紀錄，不靜默消失。
5. 保留的窗口成為新的字幕條目，與 VAD 段條目合併排序。補掃條目的起訖時間為其窗口範圍；文字較長者，依句子邊界拆成多個條目，時間依字元數比例分配，並標記為「時間為估計值」。
6. 補掃條目與 VAD 條目走相同的後續階段（潤飾、核對、翻譯、匯出），並遵守 ADR-038 決策 4 的不變式；它們另有來源標記，Console 能分辨。
7. 預設行為：開啟（`sweepEnabled` 預設 true），因為漏掉人聲的損失大於多送幾個窗口的成本；管理員可關閉。

## 取捨

| 選項 | 優點 | 缺點 |
|---|---|---|
| A. ASR 補掃空隙（採用） | 直接解決召回不足；成本低；不依賴 VAD 調參 | 時間為窗口粒度、句子切割為估計；需過濾幻覺 |
| B. 降低 VAD 門檻 | 不改結構 | 空隙內機率最高只有 0.2 至 0.3，仍補不到長段；新增的多為雜音；門檻 0.15 以下在目前規則下失效 |
| C. 音訊前處理（正規化、濾波） | 概念簡單 | 實測不改善覆蓋率 |
| D. 人聲分離 | 對有背景音樂的音訊可能最有效 | 依賴重、與薄 jar 衝突、尚無證據必要 |

## 後果

- 字幕條目不再只來自 VAD；ADR-038 的「字幕條目 ＝ VAD-B 段」改為「條目來自 VAD-B 段，或來自補掃窗口」，其餘不變式（條目數、順序、時間在轉錄後固定）不變。
- 補掃條目的時間精度低於 VAD 條目（粒度為窗口，最長 `sweepWindowSeconds`），文件與 Console 說明此差異。
- 轉錄階段呼叫次數增加（本例約 20 至 30 次，每次不到 1 秒）；對耗時的影響很小。
- 幻覺過濾規則依賴「主要語言」的判定與長度門檻，可能誤丟短的真實語句或誤留短的雜音；因此被過濾的窗口必須可查，不靜默丟棄。
- 雜音造成的中文單字在日語影片中最常見；規則針對這個樣態。其他樣態待更多樣本。
- 預設值（`sweepMinGapSeconds`、`sweepWindowSeconds`、`sweepMinChars`）由實作者依本例資料提案，架構師核可。
