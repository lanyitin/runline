# WI-1415 影片長度上限參數 maxMediaSeconds

狀態：已核可（2026-10-11），未開始。儲存庫：T。相依：WI-1406。本文回答：如何把影片長度上限變成 pipeline 的對外參數。

## 背景

WI-1406 的能力以建構子引數接收長度上限，沒有對應的 pipeline 參數。決策：新增參數 `maxMediaSeconds`，預設 21600（6 小時）。

## 驗收條件

1. pipeline 宣告選填參數 `maxMediaSeconds`，預設 21600；README 的參數表同步（既有的參數文件測試維持一致）。
2. 值必須是正整數秒；不合法（非數字、零、負數）在初始階段被拒絕並指出參數名稱。
3. 該值是音訊擷取所使用的長度上限；長度恰等於上限者被接受，超過者以「超過長度上限」失敗，訊息含上限值與影片長度（秒），不含路徑。
4. 未提供參數時使用預設 21600；以測試驗證預設值確實生效（以較小的 `maxMediaSeconds` 與真實 ffmpeg 產生的樣本驗證拒絕，預設值本身以宣告驗證）。
5. 不改變其他參數與既有行為；既有測試通過。

## 架構約束

沿用 WI-1403 的參數宣告與驗證方式；只用 JDK、core、Kotlin 標準函式庫。
