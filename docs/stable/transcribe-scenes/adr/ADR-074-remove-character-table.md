# ADR-074 移除角色表與全片摘要的出場人物

本文回答：摘要與翻譯是否仍需要角色表與人名。狀態：已核可（2026-10-16）。取代 [ADR-054](ADR-054-scene-summaries-and-translation-context.md) 的決策 4 全部、決策 5 全部、決策 6 中「角色表（含繁體中文譯名）」一項；其餘決策不變。

## 背景

- 實機的角色表只有描述性稱呼（「長髮女人」「短髮男人」），沒有任何有名字的角色；影片的對白與畫面不提供可辨識的名字。
- 有名字的判斷依賴模型，曾出現把描述性稱呼標成有名字的情形（[WI-1475](../work-items/WI-1475-retry-and-early-stop-policy.md) 為此加了處理）。
- 角色表的用途（全片摘要的人物段、翻譯的譯名一致）在名字辨識不了時失去依據。

## 決策

1. **移除角色表**：全片摘要不再產出角色表，也不要求列出出場人物；全片摘要仍依主題或故事段落組織，說明關係、主要事件與情緒變化，人物以描述性語句帶過即可。
2. **移除名字的判斷**：摘要不再區分「片中出現的名字」與「描述性稱呼」，不再有相關的重試與降級。
3. **翻譯不附角色表與譯名**：翻譯仍附場景摘要與前一片段已翻好的譯文作為唯讀語境，保留條目、行數與換人標記。
4. **摘要語言、三層結構、畫面依據、摘要不阻擋翻譯**：沿用 ADR-054 決策 1 至 3、7。
5. **既有資料**：角色表資料表保留、不再寫入；舊 run 的資料與 Console view 仍可讀。

## 取捨

- 得到：少一類回答標記與解析、少一類降級原因；摘要的呼叫不必要求模型做它做不到的事。
- 失去：
  - 同一角色在不同片段的稱呼、代名詞的翻譯可能前後不一致，沒有譯名表約束；
  - 若日後影片提供可辨識的名字，需要重新設計。
- 緩解：場景摘要與前文譯文仍提供語境；成品核對時抽查稱呼的一致。
