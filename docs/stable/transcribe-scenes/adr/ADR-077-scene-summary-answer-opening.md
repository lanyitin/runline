# ADR-077 場景摘要的回答開頭由預填固定

本文回答：thinking 關閉時，場景層摘要的回答如何避免出現自言自語（"Wait, …"）而不影響其他層。狀態：已核可（2026-10-18）。補充 [ADR-055](ADR-055-thinking-policy-and-early-stop.md) 決策 1 中「thinking 關閉的作法」，以及 [ADR-054](ADR-054-scene-summaries-and-translation-context.md)「後果」中的回答格式標記；與 stable 沒有衝突。量測依據見[量測報告](../summary-leak-experiment-report.md)。

## 背景

- thinking 關閉的作法是在請求末尾放一個已結束的空推理區塊（assistant 輪的預填）。預填之後，模型可以自由開始回答。
- 場景層摘要的輸入是片段摘要的文字。輸入互相矛盾時（地點從車內跳到臥室、片段摘要寫著「場景在此結束」），模型在回答前先用明文分析輸入，並反覆修稿，直到用盡生成上限。分析寫在 `content`，不在推理通道。
- 外洩的回答被存成正式的場景摘要，並進入下一層彙整的輸入。
- 量測結果（thinking 關閉，同一模型與取樣參數）：
  - 現行預填：容易外洩的場景 30 為 8/10，場景 18 為 4/10；全片其餘 37 個場景為 0/3。
  - 回答開頭固定為標記時：9 個場景合計 110 次，0 次外洩、0 次截斷，四個欄位皆齊全。

## 決策

1. **預填內容**：場景層摘要所用的 system 提示（場景摘要與逐層彙整的中間摘要，共用同一份提示）在 thinking 關閉時，預填已結束的空推理區塊之後，接上該提示要求的第一行標記與換行。標記取自提示本身，不另立一份。
2. **範圍**：只適用場景層提示。片段層與全片層不加：
   - 片段層帶圖片時，現行做法 0/60 外洩，沒有需要解決的問題；
   - 全片層的第一行標記後面接著語言碼，加預填使版面失效（10/10）。
3. **解析**：場景摘要的解析接受回答帶或不帶標記，並忽略開頭的空推理區塊（服務會把整段預填連同續寫一併回傳）。標記只出現一次。
4. **thinking 開啟時**：不加預填（與 [ADR-055](ADR-055-thinking-policy-and-early-stop.md) 一致）。
5. **其餘不變**：提示文字、取樣參數、生成上限、重試與降級規則不變。

## 取捨

- 得到：
  - 場景層外洩在量測樣本中降為 0；
  - 外洩案例的耗時由約 58 秒降到 1.5 秒，回答只有欄位，約 100 個 token；
  - 不需要開啟 thinking（耗時約 2 倍）、不需要改用 JSON 輸出。
- 失去：
  - 模型沒有機會在輸入明顯有問題時說明，只能照欄位填寫；摘要可能把不連貫的輸入硬湊成一段；
  - 摘要內容會補入輸入沒有的細節（如光線、髮色），預填前後都有，預填不改善也不惡化；
  - 預填依賴服務把預填當成續寫的開頭；換服務或換模型時要重新量測。
- 備選與未採用的原因：
  - **JSON 輸出**（`json_object`、`json_schema`）：與 thinking 關閉的預填並用時，服務一律回 400（取樣器初始化失敗）；
  - **開啟 thinking**：`content` 沒有外洩，但耗時約 2 倍、每次約 7,400 個 token（固定開頭約 100 個），且無格式約束的 10 次中有 1 次用盡額度而回空答案；
  - **只改輸入措辭**（片段摘要不寫 "scene"）：外洩由 10/10 降到 6/10，不足以單獨採用，但值得作為第二道防線；
  - **提示中加「不要解釋」**：已知對小模型無效（[02](../02-current-state.md)）。

## 後果

- 場景層摘要請求的形狀改變，需調整 EXCHANGE 對請求的記錄（thinking 關閉的標示不變，另標出預填含標記），好讓日後比較。
- 場景摘要的解析規則與驗收條件需涵蓋「標記來自預填」。
- 工作項：[WI-1483](../work-items/WI-1483-scene-summary-answer-opening.md)。
- 量測只涵蓋一支影片（run 38）；其他影片上的外洩率未知。
