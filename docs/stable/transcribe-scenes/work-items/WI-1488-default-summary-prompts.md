# WI-1488 場景層與片段層摘要的預設提示

本文回答：場景層與片段層摘要的預設 system prompt 要改成什麼。狀態：已完成（2026-10-18），T 的合併提交 9ed4aa4。相依：WI-1483、WI-1484、WI-1485（皆已完成並合併）。決策見 [ADR-081](../adr/ADR-081-default-summary-prompts-adopt-measured-structure.md)；提示原文見[參考文件](../run38-summary-prompts-reference.md)。儲存庫：T。

## 行為與驗收條件

1. **場景層預設提示**：
   - 要求四個欄位（`Setting:`、`People:`、`Progression:`、`Ending:`），標籤固定、順序固定、各占一行，總長不超過 1500 字元；
   - 第一行為 `SUMMARY:`，後面接四個欄位，沒有其他內容；
   - 涵蓋整個場景的要求、命名規則、規則段與形狀範例，內容依參考文件；
   - 不寫死影片語言（不出現 Japanese），不要求說明演員說的語言。
2. **片段層預設提示**：
   - 摘要一到三句、500 字元以內；最後一句寫片段的最後一刻；要求看最後一張圖；命名與規則段，內容依參考文件；
   - 不要求說明演員說的語言，不寫死影片語言；
   - 沿用 [WI-1484](WI-1484-segment-summary-wording.md) 已加入的用詞規定（單位稱為 segment，不使用 scene 一詞，結尾寫成這個片段的最後）；參考文件中提到 scene 之處改寫為不含該詞的說法；
   - 除了規定不使用該詞的那一句，片段提示不含 scene 一詞。
3. **標記**：場景層 `SUMMARY:` 加換行、片段層 `SUMMARY: `，維持契約標記；覆寫提示的規則不變（標記不得刪去）。
4. **其他不變**：全片層、潤飾、翻譯的預設提示；請求形狀（含 [WI-1483](WI-1483-scene-summary-answer-opening.md) 的預填）；取樣參數；生成上限；重試與降級規則。
5. **文件與程式一致**：守住「文件引文與程式中的提示字串完全相同」的測試隨之更新；T 的 README 摘要章節同步。
6. **解析不變**：本項不改回答的解析（欄位的裁剪由 [WI-1486](WI-1486-scene-summary-field-block-only.md) 處理）；既有的解析測試維持通過。

## 架構約束

- 不改 Engine；不改資料。
- 嚴格 TDD；測試守住：場景提示的四個標籤與順序、1500 字元上限、第一行標記、不含 Japanese；片段提示的字數與句數上限、最後一句的要求、不含 scene（除禁用句）；覆寫行為；其餘提示不變。
- 提示的實機效果（外洩、涵蓋度）由 homelab-deployer 量測，不在本項；本項回報兩份提示的完整預設值供量測使用。
- 以舊預設或覆寫值產生並被續跑沿用的摘要保持原樣，不重新產生。
