# ADR-070 翻譯回答中未翻譯的條目重試一次，只重送那些條目

本文回答：翻譯回答裡被判為未翻譯（`UNTRANSLATED`）的條目，要不要重試、怎麼重試。狀態：已核可（2026-10-15）。取代 [ADR-069](ADR-069-accept-what-can-be-used.md) 決策 5 中「不觸發重試」與決策 7 中「其他情況不重試」對未翻譯的部分；其餘不變。

## 背景

- 使用者的判斷：未翻譯的條目值得再試一次。
- 實機證據（run 28，WI-1473 之後）：16 條、9 個片段因 `UNTRANSLATED` 降級，每個片段只呼叫一次；沒有重試，降級的條目全數留下來源文字。
- ADR-069 的證據：附原因、重送整個片段的重試成功率只有 4% 至 7%，原樣回傳的片段在重試時逐字相同。本決策的重試與它不同：縮小到未翻譯的條目、不附原因，輸入較短，模型的取樣有機會給出不同結果。成效未量測，列為待確認問題。

## 決策

1. **未翻譯的條目重試一次**：翻譯回答解析後，若有條目含假名（`UNTRANSLATED`），對該片段發出一次重試。
2. **只重送未翻譯的條目**：重試請求只含這些條目（序號沿用原序號），上下文（角色表、場景摘要、前文）與提示詞和第一次相同；不附原因。已採用的條目不重送、不被覆蓋。
3. **重試後仍未翻譯的條目降級**：保留上一階段文字並記錄，不再重試。重試採用的條目照常採用；重試的回答同樣以寬鬆方式解析。
4. **共用每片段的重試次數**：未翻譯的重試與服務層失敗、空手而回的重試共用 `modelRetries`（每片段，預設 1）；設為 0 時完全不重試。
5. **不影響及早止損**：未翻譯的重試不累計失敗；片段只要取到任何一條就歸零（ADR-069 決策 8 不變）。
6. **潤飾與摘要不變**：潤飾沒有未翻譯的檢查；摘要的缺少照 ADR-069。

## 取捨

- 得到：有機會把降級的條目救回來，成本限於少數條目的短請求。
- 失去：每個有未翻譯條目的片段多一次呼叫；若模型逐字重複，成本白費。
- 不採用：
  - 重送整個片段（輸入長、成效已知很低）；
  - 附原因重試（ADR-069 已證實無效）；
  - 無上限重試。
